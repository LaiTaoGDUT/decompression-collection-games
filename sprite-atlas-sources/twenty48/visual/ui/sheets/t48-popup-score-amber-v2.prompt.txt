游戏 UI 素材：霓虹赛博电路风格的结算弹窗「最终得分」底框，单个。1536×1024 横版画布，底框水平垂直居中，约占画布宽度的 80%。

【必须遵守】
1. 透明背景（PNG 带 alpha）。底框之外完全透明，只允许边缘很淡、很窄的同色外发光；不要背景、不要地面、不要投影底板。
2. 外形：横向切角长条（四角斜切，上下边中段可有轻微的台阶切口），宽高比约 3.9 : 1（例如宽 1200、高 308）；正视图、平面 UI、无透视。
3. 底框上绝对不要出现任何文字、数字、字母、符号、图标。内部约 80% 的区域保持干净的深色平滑渐变，用来叠加大号琥珀色数字。
4. 颜色：琥珀金 #FFC62C 的细霓虹灯管边框 + 内侧一圈更细更暗的内框，四角和左右两端各有少量细电路走线和小节点；主体是很暗的深琥珀色半透明玻璃（暗，但带色相）。简洁克制，不要宝石、不要金属、不要闪光点。

【低眩光要求（最重要，优先级高于风格描述）】这套素材会在手机暗色界面上被长时间注视，必须柔和、不刺眼：
- 霓虹灯管保持该颜色本身的饱和色相，亮度中等偏上（约为该色满亮度的 75%）。灯管中心绝对不能发白、不能过曝成白色光芯。
- 外发光窄而淡：宽度不超过灯管粗细的 2 倍，透明度低；不要大面积光晕、不要光雾、不要泛光。
- 不要镜头光晕、星芒、闪光点、白色高光斑、强反光。
- 主体是带该色相的深色半透明玻璃：暗，但不是纯黑；与边框的明暗反差适中。不要整体抬亮、不要雾蒙蒙的灰色蒙层。
- 电路走线、节点比边框更细、更暗，只是次要层次。

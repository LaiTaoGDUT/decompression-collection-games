游戏 UI 素材：手机小游戏的暂停按钮图标。1024×1024 方形画布，按钮居中，约占画布的 70%，四周留透明空白。

【必须遵守】
1. 透明背景（PNG 带 alpha）。按钮之外完全透明，只允许边缘很淡、很窄的青色外发光；不要背景、不要地面、不要投影底板。
2. 外形：正方形切角（八边形，四角斜切）的霓虹按钮框：细的青色 #24DCFF 霓虹灯管外框 + 内侧一圈更细、更暗的内框，四角各有一小段电路走线和小圆点节点。框内是很暗的深青色半透明玻璃渐变。
3. 框内正中是暂停符号：两条竖直的圆角青色霓虹灯管，灯管是饱和的青色（不要白色亮芯），粗细适中、左右对称，高度约占框内高度的 45%。暂停符号是画面中最醒目的部分，但亮度与外框同级，不要更亮。
4. 不要任何文字、字母、数字。不要宝石、不要金属、不要多余图标。线条清晰，缩小到 80px 显示时仍能一眼认出是暂停键。

【低眩光要求（最重要，优先级高于风格描述）】这套素材会在手机暗色界面上被长时间注视，必须柔和、不刺眼：
- 霓虹灯管保持该颜色本身的饱和色相，亮度中等偏上（约为该色满亮度的 75%）。灯管中心绝对不能发白、不能过曝成白色光芯。
- 外发光窄而淡：宽度不超过灯管粗细的 2 倍，透明度低；不要大面积光晕、不要光雾、不要泛光。
- 不要镜头光晕、星芒、闪光点、白色高光斑、强反光。
- 主体是带该色相的深色半透明玻璃：暗，但不是纯黑；与边框的明暗反差适中。不要整体抬亮、不要雾蒙蒙的灰色蒙层。
- 电路走线、节点比边框更细、更暗，只是次要层次。

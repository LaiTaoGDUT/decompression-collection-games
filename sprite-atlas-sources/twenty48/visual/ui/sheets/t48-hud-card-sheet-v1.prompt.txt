游戏 UI 素材：霓虹赛博电路风格的 HUD 信息卡片底框，一张图里共 3 张卡片，竖向排成 1 列 × 3 行，水平居中。1024×1536 竖版画布。

【必须遵守】
1. 透明背景（PNG 带 alpha）。卡片之外完全透明，只允许卡片边缘有柔和的同色外发光；不要背景、不要地面、不要投影底板。
2. 每张卡片都是横向的圆角矩形，宽高比约 2.1 : 1（例如宽 640、高 300），三张等大；正视图、平面 UI、无透视；卡片之间留出足够大的透明间距，外发光彼此不相连。
3. 卡片上绝对不要出现任何文字、数字、字母、符号、图标。卡片中部和下部约 70% 的区域保持干净的深色平滑渐变，用来叠加白色大数字；顶部正中可以有一小段发光的标题槽（空的，不写字）。
4. 装饰只放在边框和四角：细的霓虹灯管边框、四角小段电路走线和节点，简洁克制，不要宝石、不要金属。

【风格】参考附图中的方块：明亮霓虹灯管边框、细腻电路纹、半透明深色玻璃质感、内发光。同一系列，只是颜色不同。

【颜色】从上到下：
- 第 1 张：青色 #24DCFF。
- 第 2 张：琥珀金 #FFC62C。
- 第 3 张：紫罗兰 #AC54FF。
主体是该色很暗的深色调（接近黑但带色相），边框是该色明亮饱和的霓虹光。

游戏 UI 素材：霓虹赛博电路风格的弹窗按钮底框，一张图里共 3 个按钮，竖向排成 1 列 × 3 行，水平居中。1536×1024 横版画布。

【必须遵守】
1. 透明背景（PNG 带 alpha）。按钮之外完全透明，只允许按钮边缘有很淡的同色外发光；不要背景、不要地面、不要投影底板。
2. 三个按钮是完全相同的造型：横向切角长条（左右两端 45° 切角），宽高比约 5.2 : 1（例如宽 1250、高 240），三个等大、上下对齐；正视图、平面 UI、无透视；按钮之间留出足够的透明间距，外发光彼此不相连。
3. 按钮上绝对不要出现任何文字、数字、字母、符号、图标。按钮中部约 80% 的区域保持干净的平滑渐变，用来叠加浅色文字。
4. 装饰只放在边框和两端：细的霓虹灯管边框、两端少量细电路走线和节点，简洁克制，不要宝石、不要金属。

【风格】参考附图中的旧版按钮的造型与做工：切角霓虹灯管边框、半透明玻璃质感。附图里的琥珀色和青色按钮太亮刺眼，紫色按钮又太暗，三者亮度差距过大；这次三个按钮必须是同一亮度等级。

【三个按钮亮度一致（最重要）】三个按钮的边框亮度、外发光强度、主体明暗完全一致，只有色相不同；放在一起时任何一个都不能明显更亮或更暗。主体是该色相的中暗色半透明玻璃（足以衬托浅色文字），不是纯黑。

【颜色】从上到下：
- 第 1 个：琥珀金 #FFC62C。
- 第 2 个：青色 #24DCFF。
- 第 3 个：紫罗兰 #AC54FF。

【低眩光要求（最重要，优先级高于风格描述）】这套素材会在手机暗色界面上被长时间注视，必须柔和、不刺眼：
- 霓虹灯管保持该颜色本身的饱和色相，亮度中等偏上（约为该色满亮度的 75%）。灯管中心绝对不能发白、不能过曝成白色光芯。
- 外发光窄而淡：宽度不超过灯管粗细的 2 倍，透明度低；不要大面积光晕、不要光雾、不要泛光。
- 不要镜头光晕、星芒、闪光点、白色高光斑、强反光。
- 主体是带该色相的深色半透明玻璃：暗，但不是纯黑；与边框的明暗反差适中。
- 电路走线、节点比边框更细、更暗，只是次要层次。

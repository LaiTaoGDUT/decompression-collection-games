游戏 UI 素材：手机小游戏的暂停按钮图标。1024×1024 方形画布，按钮居中，约占画布的 70%，四周留透明空白。

【必须遵守】
1. 透明背景（PNG 带 alpha）。按钮之外完全透明，只允许边缘柔和的青色外发光；不要背景、不要地面、不要投影底板。
2. 外形：正方形切角（八边形，四角斜切）的霓虹按钮框，与附图分数卡的切角边框是同一造型语言：细的青色 #24DCFF 霓虹灯管外框 + 内侧一圈更细的内框，四角各有一小段电路走线和小圆点节点。框内是很暗的深青色半透明玻璃渐变。
3. 框内正中是暂停符号：两条竖直的圆角霓虹灯管（双线发光：外层青色光晕 + 近白色亮芯），粗细适中、左右对称，高度约占框内高度的 45%。
4. 不要任何文字、字母、数字。不要宝石、不要金属、不要多余图标。线条清晰，缩小到 44px 显示时仍能一眼认出是暂停键。

游戏 UI 素材：手机小游戏「霓虹 2048」的顶部标题 Logo。1536×512 横版画布，Logo 水平居中，四周留透明空白。

【必须遵守】
1. 透明背景（PNG 带 alpha）。Logo 之外完全透明，只允许文字和线条有柔和的外发光；不要深色底板、不要背景色块、不要地面。
2. 文字内容必须准确且只有：「霓虹2048」（中文"霓虹"两个字 + 数字 2048），一行横排，字形清晰易读，笔画正确，不要错字、不要多余文字或字母。
3. 风格：霓虹灯管字——每个字由发光的空心灯管描边构成（双线：外层彩色光晕 + 内层近白色亮芯），字内部是很暗的半透明深色，不要实心填色块，不要厚重立体浮雕和金属质感。
4. 配色克制：「霓虹」两字为青色 #24DCFF，「2048」为品红 #FF3EAC 过渡到琥珀金 #FFC62C，整体只用这三种霓虹色。
5. 装饰极简：文字下方一条细长的切角霓虹线（像 HUD 分割线），两端各一个小圆点节点；不要外框、不要底板、不要密集电路、不要宝石。整体轮廓扁平修长，宽高比约 4.5 : 1。

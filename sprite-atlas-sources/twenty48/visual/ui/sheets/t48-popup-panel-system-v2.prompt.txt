游戏 UI 素材：霓虹赛博电路风格的系统弹窗（暂停菜单）底框面板，单个。1024×1536 竖版画布。

【必须遵守】
1. 透明背景（PNG 带 alpha）。面板之外完全透明，只允许边缘很淡、很窄的外发光；不要背景、不要地面、不要投影底板。
2. 外形：竖向的切角面板（四角斜切），正视图、平面 UI、无透视。整个面板（含顶部装饰和外发光）的外接矩形宽高比为 1 : 1.35（例如宽 900、高 1212），面板居中，四周留少量透明空白。
3. 面板上绝对不要出现任何文字、数字、字母、符号。面板内部是很暗的深海军蓝半透明玻璃，绝大部分区域保持干净平滑，用来叠加标题、文字和按钮。
4. 边框：细的霓虹灯管外框 + 内侧一圈更细、更暗的内框；左右两侧中段各有一小组细刻度/电路节点，四角有少量细电路走线。不要宝石堆砌、不要金属。
5. 配色：边框以青色 #24DCFF 为主，左下与右下角渐变到紫罗兰 #AC54FF。顶边正中有一颗小菱形徽记（内部是 2×2 小方格图案，像 2048 的棋盘），徽记同样是低亮度霓虹描边，不要发光闪耀。

【低眩光要求（最重要，优先级高于风格描述）】这套素材会在手机暗色界面上被长时间注视，必须柔和、不刺眼：
- 霓虹灯管保持该颜色本身的饱和色相，亮度中等偏上（约为该色满亮度的 75%）。灯管中心绝对不能发白、不能过曝成白色光芯。
- 外发光窄而淡：宽度不超过灯管粗细的 2 倍，透明度低；不要大面积光晕、不要光雾、不要泛光。
- 不要镜头光晕、星芒、闪光点、白色高光斑、强反光。
- 主体是带该色相的深色半透明玻璃：暗，但不是纯黑；与边框的明暗反差适中。不要整体抬亮、不要雾蒙蒙的灰色蒙层。
- 电路走线、节点比边框更细、更暗，只是次要层次。

# 合成大西瓜生成与节奏调参记录

> 日期：2026-08-09  
> 对应计划：第 13 步  
> 随机种子基线：`0xC0FFEE + variantIndex * 10000 + sessionIndex`

## 方法

本报告由一次性投放权重模拟得到：三组候选权重分别模拟 240 局，每局 80 次直接生成，共 19,200 次样本。模拟读取正式 `gameplay.json` 作为入选方案，并记录平均等级、高等级直接生成占比、前十次生成的等级丰富度和同等级最长连续段。一次性模拟脚本已移除，本文保留历史结果。

该记录只用于验证生成规则与相对节奏，不冒充真实物理局时、胜率或真机体验结论；投放、碰撞和完整局时仍在后续手感与试玩步骤记录。

## 决策

入选 `30/25/20/15/10`：相较均匀基线降低直接得到高等级水果的比例，保留从小水果理解“同级合成”的成长过程；同时比低级偏重方案保留更多等级 3～4 输入，避免前期过长和重复小水果堆积。投放冷却暂保留 0.45 秒，交由第 14 步结合输入与物理手感统一回归。

随机抽取只消费固定权重与随机源，不读取分数、广告、存档或用户属性。生产使用 `Math.random`；回归可以在开局前注入固定种子随机源。当前/下一个水果沿用同一独立抽取规则，等级 5～10 没有直接生成入口。

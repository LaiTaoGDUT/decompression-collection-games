# 霓光 2048 玩法规格

> 版本：1.0  
> 状态：已实现并通过规则回归与 Creator 浏览器试玩  
> 游戏 ID：`game2048`  
> Bundle：`game-2048`

## 1. 核心规则

- 棋盘为 4×4；新局生成两个数字块。
- 玩家可向上、下、左、右移动；触控使用主方向滑动，桌面调试支持方向键和 WASD。
- 同值数字在一次移动中合并，每个来源数字块最多参与一次合并；得分增加合并后的数字值。
- 只有棋盘发生变化时才生成新数字；新数字为 2（90%）或 4（10%）。
- 2048 是普通高阶里程碑，首次生成 2048 不冻结棋盘、不触发最终目标层；首次生成 4096 时冻结棋盘并显示终极庆祝层，玩家可继续挑战更高数字、完成本局或返回大厅。
- 棋盘填满且四个方向均无有效移动时结束本局。

## 2. 局内能力

- HUD 显示当前分数和历史最高分。
- 不提供撤销能力；每次有效移动和随机生成都直接成为当前局不可回退的状态。
- 输入动画期间锁定下一次移动，避免重复步；无效移动不会改变棋盘或生成数字。
- 暂停层提供继续、重新开局、返回大厅；结果层和目标层均通过公共运行上下文完成重开或退出，不直接切换场景。
- 失败结算层可关闭以查看冻结的最终棋盘；关闭后顶部按钮切换为“结算”，可随时重新打开并选择重开或返回大厅。

## 3. 存档与生命周期

- 使用独立命名空间 `game2048`、游戏内 `dataVersion: 3`。v2 → v3 将旧 `activeRound.targetAcknowledged`（2048 目标确认）迁移为新的 4096 未确认状态，并保留棋盘、分数、最高数字、最高分及未知自定义字段；不修改根存档 schema。
- 保存 `playCount`、`lastPlayedAt`、`highScore`，以及 `custom.highestTile`。
- 进入时加载 `game-2048` Bundle；暂停、切后台和退出会暂停音乐；退出后解除输入、音频与节点引用并由公共运行层释放 Bundle。
- 回滚无需迁移根存档：从公开 Manifest 移除 `game2048` 即可隐藏入口，旧版本忽略该独立命名空间。

## 4. 验收口径

- 模型回归覆盖四向压缩、单次合并、无效移动、生成概率入口、2048 普通里程碑、4096 最终目标与无步可走。
- Creator 浏览器试玩覆盖大厅进入、触控滑动、键盘合并、暂停恢复、回大厅、再次进入与最高分持久化。
- 游戏逻辑、场景、视觉和音频全部位于 `game-2048` Bundle；大厅只保存展示封面副本和 Manifest 元数据。

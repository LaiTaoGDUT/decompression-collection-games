## 1. 主题定位

《无尽剑域》是一片被灵气裂隙撕开的暗色荒原战场：玄青石地上剑痕纵横，古老阵纹微光明灭，妖魔从黑暗中成群涌来，被修士的高饱和法术之光成片斩落。整体画面必须同时满足两个矛盾诉求——环境安静低对比，让敌群轮廓清楚；技能高亮高饱和，让每次释放都有"剑光破开黑暗"的爽感。

风格定位：**动漫国风仙侠 + 高饱和法术特效 + 深色玄幻战场**。

关键词：玄青荒原、剑痕阵纹、动漫修士、灵气青光、剑光破暗、法术洪流、割草快感、境界压迫。

禁止方向（硬性，违反即打回）：

- 写实仙侠、水墨写实、3D 渲染、厚重 MMO 质感、日系二次元立绘。
- 大厅展柜皮肤、猫咪/水果纸雕、2048 霓虹电路、中国象棋书斋木雕、木框拼图玩具等任何已有游戏的视觉体系，也不得通过改色复用。
- 带版权角色、可识别品牌或可识别艺术家风格。
- 把环境做得比技能更抢眼，或把敌群淹没在特效里。

使用规则：

- 玩家侧法术固定使用青/蓝/金/紫/火/冰六色系；敌方警示与弹幕统一走危险红系，玩家与敌方的色彩语言必须一眼可分。
- 环境永远低对比、低亮度；只有技能、拾取物和警示允许高饱和。
- 经验珠使用仙金并按四级视觉递增亮度与尺寸，是地面上最醒目的中性目标。

## 3. 构图与材质

- **场景**：`1024×1024` 无缝玄青石地 Tile，含暗青石地、浅淡云纹、破碎剑痕、古老阵纹、少量碎石、灵气裂隙六类元素；装饰物 6 种，每 Tile 随机 3～6 个，不参与碰撞、不遮挡敌群轮廓。
- **角色（无名修士）**：动漫 2D、3/4 俯视角、干净轮廓、轻量细节——黑色长发、青白道袍、金色腰带、背后悬浮剑匣、青色灵气；不佩戴夸张头饰。主角是画面中唯一的"青白+金"配色，任何敌人不得抢占该配色。
- **敌人**：9 种普通怪 + 魂虫/鬼火怪 2 种衍生 + 3 精英 + 5 Boss，全部使用暗色调（墨绿、玄黑、暗紫、暗红），边缘轮廓清晰，同屏 160 只时仍可逐个辨认；精英与 Boss 用体型、金色纹路和出场阵法拉开层级。
- **技能特效**：高亮度、短生命周期、命中即峰值后快速衰减；地面持续型技能（火场、毒区、重力领域）用半透明贴地材质，不遮蔽站桩的敌人。
- **警示层**：所有敌方范围伤害（爆魂、地震、雷区、冲锋路线）统一红色危险圈/预警线，线宽与持续时间保证 0.55 秒预警内可读。
- **HUD**：深色 UI 底板 + 灵气青强调；顶部 HP（危险红渐变）、中部时间与境界、XP 条仙金；右侧技能图标列最多 11 个，数量增多时自动缩小。
- **升级三选一**：纵向卡牌，深色底 + 灵气青描边，进化配方用仙金小字；卡牌不烘焙中文，动态文字由 Label 绘制。

## 4. 文字与交互

- 标题与数字使用清晰的中文无衬线字体，风格偏"剑意硬朗"；伤害数字（暴击/精英/Boss 才显示）使用锐利数字字体，白/金/红三档。
- 主要操作文案固定为："开始修行""境界感悟""刷新 ×2""暂停""继续游戏""重新开始""返回大厅""看广告继续""本局结束"；新手提示："按住并拖动移动""攻击会自动释放""选择一种能力，构筑你的流派""击败 Boss 可以让满级技能进化"。
- 按钮覆盖默认、按下、等待、禁用、失败状态；按下用轻微下沉 + 描边亮起，不只靠变色。
- 浮动摇杆全屏游戏区生效，触摸区域不小于 88×88 设计单位；摇杆本体低透明度，不遮挡敌人。
- 常驻控件（暂停按钮）位置由 `PlatformSafeLayout.calculateTopRightControlPosition` 计算，避让微信胶囊，禁止写死坐标。

## 5. 动效与声音方向

- **总原则（策划案 §99）**：先结算后播放动画。敌人 HP≤0 立即逻辑死亡并回池，死亡表现（缩放 1→1.15→0、旋转 ±12°、淡出 0.22 秒）只是表现层，不得由 Tween 回调决定生死。
- 命中表现：普通怪白闪 0.06 秒，暴击 Scale 1→1.08→1，Boss 白闪 0.04 秒；避免高频抖动。
- 震屏：强技能 6px/0.12s，Boss 重击 8px/0.15s，Boss 死亡 14px/0.35s，连续触发不叠加超过 16px。
- 演出节点：Boss 出场阵法、境界突破金光、灾厄警告红字压屏、技能进化全屏提示——均不阻塞逻辑，不遮挡玩家对危险圈的判断。
- **声音身份**：两首 BGM——战斗 125 BPM（东方鼓点 + 古筝/琵琶 + 电子低频，90 秒无缝循环）、Boss 138 BPM（重战鼓 + 快速弦乐，75 秒无缝循环）；约 30 个 SFX 以短促法术cue 为主。不得使用 T48 电子脉冲、纸片水果音、棋类木音、拼图纸卡音等任何已有游戏的声音身份。
- 音频限流（策划案 §98）：XP 拾取 ≤8 次/秒、敌人命中 ≤10 次/秒、飞剑最小间隔 0.08 秒。

## 7. 适配与验收

- Cocos `Fit Width`，基准 750×1334；横向占满左右屏幕边界，纵向避让微信胶囊与底部安全区，左右系统安全区不参与布局。
- 矮屏压缩顶部 HUD 约 18%、缩小升级卡高度，不压缩 Gameplay 尺寸；超长屏只显示更多世界区域，不放大角色与敌人。
- Canvas 的 `_cameraComponent` 必须显式绑定本场景 UI Camera；Canvas、UI Camera、UI 根节点同一 UI Layer，世界层与 UI 层隔离。
- 生成位置、摇杆、HUD 布局全部读运行时 `view.getVisibleSize()` 与 `Platform.getLayoutInfo()`，禁止写死机型坐标。
- 视觉验收至少包含：无胶囊 Web、窄屏、短屏、刘海/挖孔、超长屏、不同底部安全区、低档真机降级。
- 割草专项验收：同屏 160 敌人 + 160 投射物 + 80 VFX 时，敌群轮廓可辨、危险圈可读、技能与敌方弹幕色彩不混淆、帧率达标；退出后无音频/动效/节点残留。

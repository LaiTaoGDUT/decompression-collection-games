## 2. 独立声音身份：C1「软绒纸雕猫屋」

猫咪游戏的画面是柔和的绘本式猫咪房间、圆形猫咪泡泡、奶油色面板和低刺激的粉彩色。声音应让玩家感觉是在一个温暖、软绵、没有压力的猫咪小房间里整理和养成猫咪，而不是在木质玩具、霓虹街机或传统棋盘中操作。

- 核心关键词：柔软、圆润、绘本、粉彩、棉布、软绒、纸雕、奶油陶瓷、轻盈、安抚。
- 主要材质：短绒布和棉花的柔软摩擦、厚纸浆或纸雕的轻折、软垫碰撞、圆润的奶油陶瓷轻触、很小的糖果感亮点。
- 能量曲线：普通操作安静清楚；合成有满足感；连锁更活泼；危险有克制的压力；失败是温和收束；续玩、里程碑和新纪录积极但不过度庆祝。
- 空间与混音：以近场、居中、干净的声音为主，只保留很短的柔和空间感；适合手机扬声器，不能依赖极低频或宽阔立体声才听得见。
- 音乐方向：低密度原创器乐循环，使用柔软的 felt mallet、轻柔拨弦、低密度粉彩钟音和温暖空气垫；旋律只能是稀疏的小动机，不能抢过投放、碰撞和合成反馈。
- 里程碑与新纪录的区别：`milestone` 表示“发现了一只新猫咪”，应更可爱、更像揭晓；`record` 表示“分数突破”，应更自信、更像成绩确认，不能做成同一条奖励音的改调版本。

禁止把其他小游戏的声音身份带入本游戏：不要使用滑块拼图的硬木框、木片滑槽和复古玩具感；不要使用 2048 的霓虹电子脉冲；不要使用象棋的木棋子、墨刷和庄重铜玉声。也不要使用真实猫叫、喵声、人的笑声、对白、品牌提示音、版权旋律或对特定艺术家的模仿。

## 3. 共用制作基线

- BGM 请求原创 instrumental game music；默认无歌词、无人声、对白和完整主歌副歌结构。
- 除 BGM 外，所有文件都是独立 one-shot；每个文件只表达一个游戏事件，不要把多个 takes、多个事件或不同版本拼在同一个文件中。
- 所有音效开头不要留空；瞬态要在手机小音量下仍然清楚；尾音短而可控，不要用长混响掩盖事件边界。
- 先保留干净的 48 kHz WAV 母版，再根据实际包体和手机扬声器听感制作运行时 MP3。外部平台的压缩预览不要直接视为候选发布文件。
- 下文的时长是生成和剪辑建议范围，不是现有文件的测量值；最终以人工试听、峰值检查、重复疲劳和游戏内遮蔽测试为准。
- 生成后记录外部平台、模型或模式、生成日期、完整提示词、输出 ID/URL、选用版本、丢弃版本、适用许可条款和所有后处理步骤，并与最终文件一起保留。

- 混音：中低密度、居中、手机扬声器可还原；高频不能持续刺耳，低频不能盖住碰撞和合成音效。

## 16. 接入与素材验收

### 生成后的文件路由

所有通过人工生成和验收的运行时文件归属 `game-watermelon`，放入：

```text
assets/games/watermelon/visual/audio/
```

文件名保持本文的 `w1-*-v1.mp3` 约定。每个音频导入 Cocos 后都应生成对应 `.meta`，不要把外部平台预览文件或未确认许可的文件直接标记为候选发布素材。

### milestone 的代码接入

当前 `WatermelonGame.ts` 已调用：

```ts
this.context?.services.feedback.play('milestone');
```

`WatermelonGame.ts` 已在 `BundleAudioBank` 的 `optionalCues` 配置中预留：

```ts
optionalCues: {
    milestone: 'visual/audio/w1-milestone-v1',
},
```

在音频文件尚未导入时，可选 cue 会跳过加载，不影响其他音乐和音效；生成并导入该文件后，`FeedbackService` 会注册并播放它，同时保留里程碑的重度震动反馈。

### 最终验收清单

- BGM 首尾无缝，暂停、失败、退出和重新进入时没有残留播放。
- 碰撞 3 个变体能听出微差，连续碰撞不爆音、不疲劳；不与合成音混淆。
- `fold`、`merge`、`chain` 的先后层次清楚；连锁不会遮蔽普通合成。
- `danger` 只表达“还有机会整理”，`failure` 才表达本局暂停。
- `continue` 表达恢复机会，`record` 表达分数突破，`milestone` 表达新猫咪发现，三者不能只是同一奖励音的改调版本。
- 在音乐开启/关闭、音效开启/关闭、震动开启/关闭三组设置下试听；音效关闭时不得产生音频，震动关闭时不得产生震动。
- 在手机扬声器和耳机上分别检查瞬态刺耳、低频遮蔽、长尾、重复疲劳和峰值失真。
- 将外部生成信息、许可条款、选用版本、后处理记录、最终路径和 Bundle 归属与最终文件一起保留。

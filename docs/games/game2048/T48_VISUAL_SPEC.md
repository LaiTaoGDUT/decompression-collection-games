# T48 《霓虹 2048》视觉规范

## 独立方向

- 主题名：霓虹晶核矩阵。
- 关键词：深海军蓝、青紫霓虹、晶体棋子、细线电路、克制发光、科幻 HUD。
- 主色：深军蓝 `#020616`、面板蓝 `#0B1636`、电光青 `#1EF5FA`、紫罗兰 `#B54EFF`。
- 状态色：2048 里程碑使用晶核金 `#FFD837`；4096 最终目标使用品红 `#FF4BC5`。
- 字体层级：标题粗白字，数字与英文 kicker 使用稍宽字距，说明文字使用低一级的浅蓝色。

## 弹窗原型基线

- 暂停、结算、2048 达成和 4096 达成共享“晶体控制舱”家族语言，但不共享完全相同的信息构图。
- 暂停/系统弹窗显示宽度为 `570`，并严格保持底图 `520:700` 的宽高比；结算弹窗显示宽度为 `580`，保持底图 `520:730` 的宽高比；达成弹窗显示宽度为 `600`，保持底图 `548:780` 的宽高比。
- 顶部徽记到主标题之间保留约 `105–130` 设计单位的背景呼吸区，不能让标题内容贴近顶框装饰。
- 正式弹窗不显示 `SYSTEM // 2048`、`RESULT // 2048`、`ACHIEVEMENT // 2048` 或 `TARGET COMPLETE // 4096` 等英文状态小标。
- 2048/4096 达成标题位于目标棋子上方，不显示“成功点亮 XXXX”副标题；2048 标题固定为“恭喜你达成”。2048 的标题、棋子和本局得分整体下移 `32`，4096 下移 `18`，按钮仍保持统一底部基线。
- 所有弹窗从底框反向排列按钮，最后一个按钮到底框固定保留 `58` 设计单位，不允许各弹窗分别写死按钮纵坐标。
- 运行时必须根据顶部胶囊与底部安全区剩余空间整体等比缩小，不得通过裁切、压缩单个间距或越界容纳内容。
- 达成弹窗中的核心棋子固定为 `190 × 190`，保留环形能量场，不得挤占标题或操作区。
- 弹窗按钮显示尺寸为 `460–470 × 86`；三按钮弹窗的末按钮与底框保留不少于 50 设计单位的视觉留白。
- 按钮使用切角晶体轮廓：青色填充为主操作，金色/品红描边为状态操作，深蓝紫边为退出或次级操作。
- 弹窗显示时屏蔽棋盘输入，底层棋盘保留可辨识轮廓，但不与文字争抢对比度。

## 禁止方向

- 禁止白色通用卡片、SaaS 式对话框、厚重拟物金属、奇幻宝箱、金币礼花和过量粒子。
- 禁止复用大厅或其他小游戏的正式色板、按钮、图标、HUD、弹窗和特效。
- 禁止因为矮屏直接隐藏操作、缩小触控区或让弹窗越过安全区。

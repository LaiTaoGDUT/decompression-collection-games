# 补行图标 v2 效果确认

本版是确认图，尚未替换运行时资源。它使用三颗糖果泡泡组成上升汇聚的小组，并用两道很轻的弧线表达“补入”，不使用文字、加号或大箭头。正式接入时会裁切透明边并按下降图标的实际显示尺寸缩放。

提示词：

Create ONE very simple standalone raster HUD icon for a glossy candy bubble-shooter mobile game. The icon means REFILL BUBBLES / ADD BUBBLES. Use only a compact group of three glossy candy bubbles, arranged as a small rising cluster: two bubbles at the bottom and one bubble slightly higher in the center, with a subtle curved upward motion arc behind them. The rising cluster itself must communicate bubbles being added. No large downward arrow, no row of bubbles, no plus sign, no text, no numbers, no letters, no panel, no frame, no cloud, no extra objects. Pink, sky-blue, and golden-yellow bubbles with the same polished candy material, rounded highlights, saturated but soft colors, clean silhouette, readable at 42x42 pixels, subject fills about 80% of a square canvas. True transparent RGBA background, never a checkerboard. Front-facing, polished game HUD icon, minimal and friendly, only the single icon.

## 完整提示词

Use case: stylized-concept. Asset type: art-direction comparison sheet for four DISTINCT bubble shooter worlds. Create a premium crisp 4 by 5 grid of exactly 20 spherical game tokens on pale warm gray. Landscape 3:2, large readable circles, equal diameter, clean regular rows. Column headings RED, YELLOW, BLUE, PURPLE, SUPPORT. Small row headings CLOUD CANDY, DEEP SEA, DESKTOP TOYS, MAGIC. This is a visual review sheet.
CRITICAL: Each row is a completely different set of collectibles with its OWN distinct imagery and material. The ONLY shared property of the four colored columns is dominant base color (coral red, golden yellow, saturated sapphire blue, violet purple) and strict circular silhouette. Do not reuse the same emblem in different rows. No generic repeated hearts, stars, droplets or grapes across all themes. Every token is exactly a front-view circle with all design details INSIDE the circle. No outside projections, floaters, ground shadows or glow, not flat badge icons. Sculptural playful 3D spheres, sharp edges, uncluttered large emblems, not tiny white marks, not a realistic photograph. Attractive rounded game-quality forms legible at 55 pixels. Consistent upper-left highlights and slight darker outline. Material differentiation must be clear.
ROW CLOUD CANDY: thick transparent gummy candy spheres, minimal sugar flecks, sculpted fruit candy embedded prominently within each sphere: RED strawberry with subtle seeds; YELLOW lemon slice; BLUE blueberry pair with little crown-shaped calyx; PURPLE grape cluster. All strongly color-coded.
ROW DEEP SEA: softly translucent nacre sea-glass/pearl spheres with subtle waterlight, sculpted marine forms inside: RED scallop shell, YELLOW rounded five-armed starfish with a few simple bumps, BLUE spiral conch shell, PURPLE small jellyfish with flowing short tentacles all inside the circle. Avoid jewelry-like excessive trims.
ROW DESKTOP TOYS: colorful molded resin/enamel toy balls with simple tactile rims: RED large four-hole toy button, YELLOW chunky six-tooth toy gear, BLUE rounded two-by-two stud building brick face, PURPLE four-blade toy pinwheel. Each emblem remains embedded within the spherical outer boundary.
ROW MAGIC: polished colored crystalline glass orbs with restrained inner faceting and sculptural magic symbols: RED sculpted flame, YELLOW radiant sun seal, BLUE frosty hexagonal ice crystal, PURPLE crescent and one tiny magical diamond. Keep the crystal's outer contour perfectly smooth and circular, not polygonal.
SUPPORT COLUMN: neutral graphite/slate and ivory colors, visually solid indestructible support objects, no matchable strong colors and NO shared generic bolt repeated across rows. Cloud: dense gray-white round hard sugar biscuit, chunky embossed cloud-shaped ceramic center, minimal thick rim, NOT a fluffy actual cloud. Deep sea: dark ancient round ocean stone with large sturdy anchor relief and restrained worn bronze ring. Desktop: steel toy bearing sphere with large central hexagonal screw head. Magic: dark stone orb with broad interlocking rune bands and a gray crystal core. Each must read as unbreakable, heavy and unable to match colored tokens. All strictly circular. Clear premium casual-game style, not industrial photorealism. No arrows, no labels inside spheres, no backgrounds/scenes/boss/UI panels. No repeated icons between worlds.

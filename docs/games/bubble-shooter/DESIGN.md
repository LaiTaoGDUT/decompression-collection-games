# 玩法与流程基线

本文整理当前有效决定。被后续取代的规则见 [DECISIONS.md](DECISIONS.md)，视觉见 [VISUAL.md](VISUAL.md)。数值未明确锁定时不得从效果图反推。

## 1. 体验与单局循环

- 普通阶段：舒缓解压，允许慢慢观察和瞄准。
- Boss 阶段：轻策略，利用消除效率、掉落与区域干扰规划发射；无实时攻击倒计时。
- 流程：区域开局 → 消除当前棋盘 → 清空所有可消除珠并取消待补行 → 当前球结算完成 → 撤走普通支撑珠 → Boss 专属布局与登场 → 击败 Boss → 三种道具选一个 → 换区域 → 继续无尽 → 触线失败 → 广告复活一次或结算。当前先运行云端单场景，其他区域按接入进度开放。
- 单区域正常操作时长目标：普通约 2～3 分钟、Boss 约 1～2 分钟，第一站偏短。只是调试目标，无时间限制。
- 后期难度跟随本局完成区域数增长，优先机制数量/组合/布局变化，不单靠堆进度与血量拖长时间。

## 2. 区域随机

四个世界：云端软糖旅行、深海微光漫游、桌面玩具远征、魔幻世界冒险。

- 每局起点从四区域等概率随机。
- 每轮四个区域不重复，从尚未访问的区域抽取下一站。
- 四个走完重新打乱，跨轮第一站不得与刚离开的区域相同。
- 所有主题都有前期和后期版本，主题不决定固定难度。
- 开始新一轮不重置本局成长进度、道具或复活消耗。

## 3. 基础操作和棋盘

- 单手竖屏，规则六角交错格，长行 13 颗、短行 12 颗，棋盘宽度 720。
- 按住玩法区域拖动瞄准，松手发射，支持取消；取消手势具体细节待定。
- 发射器拆为固定底座和可旋转炮台。炮台角度与瞄准轨迹共用同一个发射方向计算结果，不维护独立逻辑角度；当前球的位置由炮台球槽带动，但球体视觉抵消炮台旋转，使心形、星形、水滴和葡萄纹样保持正立。下一球和交换图标不旋转。
- 当前球结算完才能发射下一颗；飞行、掉落、Boss 行动、换景期间锁定相关操作。
- 至少三颗同色相连消除，不要求直线。
- 消除后，不连顶部或有效特殊支撑点的泡泡掉落。
- 支持左右墙反弹；瞄准线展示一次反弹及预计吸附格，预览与实际发射必须共用判定逻辑。实际最大反弹次数和角度限制待细化。
- 显示当前球和下一球，可无限次交换；交换不推进任何行动计数。
- 四区域只保持红、黄、蓝、紫的颜色对应关系和碰撞尺寸一致；每个区域使用独立的珠子主体图案与材质，不复用同一套辅助纹样只换皮。2026-09-20 用户要求覆盖旧的跨区域统一纹样约定。

## 4. 供球

已接受“棋盘有效颜色 + 温和防连续坏球”。

- 新球仅从棋盘仍存在的普通泡泡颜色中选择；综合数量和可接触边缘分布，适度提高可利用颜色概率。
- 连续若干球未消除后，如果存在可直接消除的颜色，适度提高其概率；不保证每球消除。
- 已展示当前球和下一球不因交换或普通棋盘变化暗中重抽。
- 颜色被彻底清空后，点击替换球或换球按钮可免费刷新过期颜色，不显示额外文字提示；符文变色后暂时消失的颜色也沿用此原则。
- 防坏球使用“连续未消除”计数，成功消除结束连续状态；普通补行使用“累计未消除”计数，不混用。
- 第一版从 4 色验证；第 5、6 色是否加入及时间待试玩。权重、保护阈值、不可匹配特殊泡泡参与颜色统计的细节待定。
- Boss 沿用供球基本原则。

## 5. 普通阶段：有限彩色补行与实体支撑

- 一次发射未触发有效消除，下降计数加一；成功消除（包括炸弹、万能球、清底）保留已累计进度。累计达到 3 后实际补行／下降，才重置此计数；清盘换阶段、复活、重开仍按各自流程重置。
- 初始棋盘与开局预定的后续彩色行构成有限内容；后续行数由难度配置控制，当前各档为 2/3/4/5 行。
- 达阈值后顶部补一行，已有泡泡整体下移，计数归零。后续彩色行用完后，每次改补一整行不可消除支撑珠，不再凭空下移棋盘。
- 支撑珠占用真实格子，可被碰撞、吸附并挂住彩珠；不参与匹配、颜色统计、冻结和道具清除，不会悬空掉落。
- 常驻提示为下降箭头与小槽位；还有彩色后续行时显示补行图标，耗尽后隐藏该图标。
- 清空当前棋盘所有可消除珠时立即进入 Boss，支撑珠不计入清盘目标。清盘优先于本次下降和危险判定。
- 提前清空时丢弃全部待补彩色行和旧存档迁移保留行，不再补珠；普通匹配、炸弹、清底、复活清盘统一遵循此规则。
- 实际消除与悬空掉落继续计入内部统计；Boss 过渡撤走支撑珠不增加收益。复活清除不增加收益，但可以完成清盘。

## 6. Boss 战：当前有效规则

**没有棋盘弱点、没有核心格、没有接近目标才扣血的条件。**

- 任意位置正常消除都造成伤害，悬空掉落追加伤害。
- 炸弹、清底实际清除也贡献伤害；万能球按正常消除处理。
- 只解除糖霜、没有实际清除泡泡时不造成伤害。
- 倾向按清除数量结算，每颗只计一次，不先引入复杂连击倍率；单颗伤害、掉落权重、Boss 血量均待平衡确认。
- 每次发射推进 Boss 总发射计数，成功消除也推进；计数满，补一行并执行专属技能，共用一次行动倒计数。
- UI：向下箭头 + 区域技能图标 + 共用槽位；不同时放普通补行计数。
- 结算：发射 → 匹配/消除/掉落/伤害 → 判断胜利 → 若存活且到点，补行及技能 → 危险线检查。
- 胜利优先，致胜球不再触发 Boss 行动。补行后技能目标跟随对应泡泡，失效目标处理待细化。
- 消除/掉落汇总成短暂能量飞向顶部 Boss，受击形变、闪光、血条减少；不是常驻连线。

## 7. 四区域机制

### 云端软糖：糖霜包裹 / 软糖布丁王

- 糖霜泡泡内部颜色可见，有糖霜时不参与同色匹配。
- 相邻的一组同色消除去除糖霜，一次可影响多个糖霜泡泡。
- 去霜后变普通球，从后续发射参与匹配，不立即自动二次消除。
- 有糖霜也可失去支撑后直接掉落；炸弹/清底可直接清除；万能球通过正常消除去除相邻糖霜。
- 前期少量分散，后期加强但保留可接近的正常色块。
- Boss 到点补行，并给少量普通泡泡添加糖霜，提前标记目标。
- 原“核心先剥甲”已随弱点机制取消；不要给 Boss 恢复独立核心护甲。

### 深海微光：不可消除支撑珠 / 章鱼

- 普通开局分散放置 4 颗不可消除锚形支撑珠，彩色补行可以新增；棋盘和迁移保留行的散落支撑总上限 6，完整压力支撑行另计。
- 不参与同色匹配、供球颜色和普通清盘目标，不冻结，也不能被炸弹、清底或复活直接移除。
- 支撑通过相邻珠子传递，断开与顶部连接后，锚珠及其下方珠子仍会自然掉落；不将散落锚珠当成悬空的独立固定点。
- 章鱼每 3 发补行并随机将最多 2 颗普通彩珠原位转化为锚珠，不持续用腕足挂住彩珠。致胜伤害优先，不再施法。
- Boss 血量未清零而棋盘只剩支撑时，保留支撑并补回可玩的彩珠。
- 正式美术采用已确认章鱼 v7、蓝绿透光遗迹背景、珊瑚过渡和珍珠金属炮台。举杖蓄力后水流飞向目标，命中时切换锚珠并出现双层波纹。
- 暂停、复活使用通用面板与章鱼叠顶；三选一只替换上方“深海凯旋”庆祝图，中下部统一。

### 桌面玩具：轨道滑动 / 积木机器人

- 同一横排的短连续格段为轨道，位置相对该局部棋盘固定。
- 到点向箭头方向同时尝试移动一格：目标为空或目标泡泡本次也能前移才可移动；端点/阻挡则停。
- 不环绕，不挤出棋盘，每次行动后方向反转；满轨道本次不动，初始布置留空格。
- 整段移动后统一检查支撑、掉落；轨道不提供支撑。
- 移动形成同色相连不自动消除；瞄准时静止。
- 普通阶段轨道按总发射次数，补行按累计未消除次数；预告方向和剩余发射次数。
- 普通补行时轨道随局部棋盘下移，离开有效范围后移除。
- 普通阶段推荐顺序：球结算 → 进度判断 → 到点轨道移动/掉落 → 再判进度 → 到点补行 → 危险线检查。与其他边界统一见待定事项。
- Boss 到点补行并移动轨道，共用 Boss 计数；不再有固定核心或围绕核心移动的规则。

### 魔幻世界：符文变色 / 符文魔像

- 少量泡泡带符文环，绑定两种已启用颜色，主体显示当前色，小标记显示下一色。
- 按总发射次数统一切换，瞄准时不变，切换后不自动消除。
- 按当前色匹配、普通支撑规则掉落，炸弹/清底可清除。
- 万能球按吸附时当前色处理；待发球不因变色偷偷改色。
- Boss 到点补行并切换符文泡泡颜色，共用计数。
- 造型方向为悬浮石块、符文与发光晶石组成的魔像；晶石可以是本体装饰，不能恢复棋盘弱点机制。

## 8. 三种一次性主动道具

| 道具 | 当前效果 |
| --- | --- |
| 炸弹球 | 替代本次发射，清除落点周围普通泡泡和可破坏障碍，再结算掉落；范围待定 |
| 万能球 | 吸附后依据邻接颜色配色，满足三连正常消除；多色选择优先级待定 |
| 清底 | 预览并确认后，清除棋盘最下方两行内的普通泡泡/可破坏障碍；行的精确选取待定 |

- 每局开场各 1 个，每类最多 3 个，三个固定按钮显示数量，无独立背包。
- Boss 胜利后固定展示三种，选一个加入库存，不是随机强化池。
- 已满类型不可领取，三种都满可直接继续。
- 跨区域、广告复活保留，结算后清空。
- 稳定待发射时才可用。炸弹/万能实际发射消耗，可取消，原普通球保留；清底确认执行消耗。
- 炸弹/万能发射算一次 Boss 行动；清底不推进也不重置计数；交换/取消不计。
- 原“不对 Boss 造成直接伤害”已取消；当前实际清除均可贡献伤害。
- 奖励卡先选中再确认、库存满态和三类全满继续已实现并确认。

## 9. 失败与广告复活

- 无玩家生命值。泡泡/障碍触及底部危险线，在相关结算完成后仍未解除则失败。
- 冻结棋盘，提供广告复活和结束本局；每局最多一次成功广告复活。
- 复活清理危险线附近普通泡泡/可破坏障碍，直到最低占用行距危险线至少留出两行空间。
- 普通区域进度、Boss 已受伤害保留；复活清场不给额外进度或伤害。
- 道具、当前/下一球保留，失效颜色可按免费刷新处理。
- 普通补行累计归零，Boss 重新开始一轮完整倒计数。
- 复活成功直接关闭弹窗并恢复游戏，不弹成功确认，不自动发射；后台完成时待前台恢复。
- 广告未完成/加载失败不消耗机会，仍可重试或结算；广告接入与状态恢复通过平台服务/应用状态机。
- 曾讨论弱点安全位置和核心护甲保留，因弱点已取消而不适用。
- 普通轨道/变色独立计数如何复位、锚点清理后连接重算等边界待进一步明确。

## 单场景实施阶段（2026-09-13）

当前先交付云端单场景完整循环；多区域随机轮换是后续阶段。云端难度封顶、布局变化和存档续局的已实现约定见 SINGLE_SCENE_STATUS.md。暂停回大厅/关闭后保留当前局；主动结束和重开不续旧局。音乐音效先空槽与提示词，不生成实际音频；真实广告和真机验收由用户后续负责。

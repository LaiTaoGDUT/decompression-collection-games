# 2026-09-20 珠子与支撑珠更新

## 用户已确认的功能要求

- 普通阶段有限彩色补行用完后，下降时在顶部补一整行不可消除的支撑珠，替代移动隐形天花板。
- 支撑珠占用真实六角格，正常阻挡飞行、允许其他珠子吸附并沿连接链提供支撑。
- 支撑珠不参与同色匹配，炸弹、清底和复活清除均不能移除它；不进入供球颜色统计，也不计入待清盘彩珠数量。
- 清空所有可消除珠子且后续彩珠队列已空时进入 Boss；支撑珠不阻止过关。Boss 入场换盘时随旧棋盘整体撤走。
- 保留原有顶部基准、交错列宽、下降出生动效和触线判断。需要处理 v7 移动天花板存档的迁移，在其空出的顶部格补足实体支撑。

## 已确认的视觉方案

v1 已被用户否决：只换材质而复用心形、星形、水滴、葡萄，不符合不同场景使用独立珠子主体的要求。新方案只保留颜色对应关系，每个场景的图案和材质独立设计。

v2 已被用户否决：云端水果偏离云朵主题，整体过于复古老套、拟物厚重。当前要求为现代、简约、清新、易看、舒适。

v3 已被用户否决：过于扁平简约。用户要求回到 v2 基础优化，现代化一点、亮堂一点。

v4 使用内置 imagegen 直接编辑 v2：保留饱满球体、立体主体和材质层次，采用明亮柔和光照、干净表面，减少厚边框、复古金属、杂碎纹理与密集切面。云端仍修正为天空元素，不恢复水果。用户认可玩具与魔幻两套；天空和海洋材质太像，需要拉开差异。

v5 只调整天空材质：改成不透明、柔润、奶油般的搪瓷/瓷釉球体，保留饱满立体的天空主体，使用宽柔高光，去掉透明球壳、水光折射与碎亮点。天空以 v5 为正式制作参考。玩具和魔幻以已认可的 v4 为正式制作参考，不受后续局部效果图重绘影响。

| 场景 | 普通珠材质 | 支撑珠材质 |
| --- | --- | --- |
| 云端 | 饱满云朵、太阳、雨滴、月牙，不透明奶油搪瓷球体 | 云纹与加固带的不透明灰白瓷质球 |
| 深海微光 | 扇贝、海星、海螺、水母悬浮于有纵深的透明水球，水波折射与少量气泡 | 浅银蓝锚纹的湿润灰石球，柔和水光反射 |
| 桌面玩具 | 立体纽扣、齿轮、积木、风车，干净树脂材质 | 简洁银灰螺钉轴承球 |
| 魔幻世界 | 立体火焰、太阳印记、冰晶、月牙，稀疏宽大晶面 | 宽束带包裹的烟灰晶核球 |

v6 仅强化海洋的水下感：主体悬浮于透明水体，增加前后层次、宽柔的水波折射和少量小气泡，保留四色主色避免整体染蓝。用户已回复“就按这个方案”，海洋以 v6 为正式制作参考；天空采用 v5、玩具与魔幻采用 v4。

四主题只统一红、黄、蓝、紫的底色对应关系，不再统一主体纹样。支撑珠保持中性、坚固、不可匹配的视觉语义，外形细节也随场景变化。

已完成：效果图确认 → 内置 imagegen 逐颗生成 20 张高清图 → 本地透明边缘清理与严格正圆裁切 → 正式素材入库。每张原图为 1254×1254 RGBA；运行素材统一 256×256，圆周与图片四边相切，不含外发光或投影。源图和每颗提示词位于 art-source/bubbles-hd/{cloud,ocean,toy,magic}/，processing.json 记录每张图的裁切范围及运行路径。

## 已实现的支撑珠与接入范围

- 当前云端场景已替换四色珠（棋盘、装填球、下一球和飞行球共用新 SpriteFrame），新增场景序列化 supportFrame 引用。
- 彩色补行队列耗尽后的每次下降，会补入一整行实体支撑珠，并播放随棋盘下移的出生动效。支撑珠参与碰撞、吸附和支撑；所有匹配、冻结、海草挂接、道具清除、供球和过期颜色刷新均排除它。
- 清盘判断只统计可消除珠；普通匹配、清底、复活均可触发清盘进入 Boss。复活清除不计额外收益。
- 存档升级 v8，保存实体支撑珠；v7 隐形天花板上方的空行迁移为实体支撑行，保留彩珠位置。更早的布局迁移继续兼容。
- 四套资源位于 assets/game-assets/bubble-shooter/visual/regions/{cloud,ocean,toy,magic}/bubbles/，各自独立 Auto Atlas。当前启动场景只引用云端珠子；其他三套素材已入库，仍随后续各区域玩法/场景接入加载，没有为了展示素材而启用未完成场景。
- 20 张 PNG 合计约 1.81 MiB。验证覆盖正圆透明遮罩的旋转对称、边界相切、内部无透明孔、唯一 UUID、尺寸元数据与场景引用。
- 素材总览含大图及 55px 缩略图：[正式珠子总览](references/bubbles-hd-production-review.png)。

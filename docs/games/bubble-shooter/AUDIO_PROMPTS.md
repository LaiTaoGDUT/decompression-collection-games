# 泡泡龙音频制作提示词与接入表

2026-09-13。当前全部音频槽为空，未生成、合成或导入任何音频文件。以下是按已确认云端软糖美术拟定的原创声音方向，供用户在外部平台手动制作；不是已试听通过的成品。

## 音频资产

所有音频只属于泡泡龙资源 Bundle `game-bubble-shooter-assets`，计划目录 `assets/game-assets/bubble-shooter/visual/audio/`，不复用大厅或其他游戏音频。声音身份：圆润弹性糖珠、薄糖霜细碎声、疏朗木琴与轻拨弦。避免尖锐高频、湿黏口腔音、真实暴力爆裂以及持续警报。

## 空槽接入方式

打开 BubbleShooter.scene，选 Canvas/GameRoot 的 BubbleShooterGame 组件，audioSlots 已序列化 28 个 cue（云端/通用 24 个、深海 4 个），每个 clips 数组为空。后续将相应音频放入计划目录，由 Cocos 导入后拖到同名 cue 的 clips；循环音乐只用第一条，音效多条按顺序轮换。不要改 cue 名称。场景静态依赖由现有 AssetService/场景流程管理，不使用业务层 bundle.load，也不请求不存在的文件。无需提供空白 WAV 或零字节文件。

播放通过 Context 的 AudioService；沿用全局音乐/音效开关。暂停冻结音乐并屏蔽玩法音效，暂停按钮 ui 音可播放；普通/Boss 切换音乐，奖励/失败停音乐，恢复/下一段播放对应音乐；退出停止音乐并清理本游戏引用。音效按事件聚合并限频（多数 65ms，Boss 受击 120ms），通过 AudioService 的本局可停止通道播放，最多 6 个；暂停/后台/关闭音效时停止，退出释放。当前空槽安静跳过，不影响游戏。真实音频的听感与循环质量待用户提供文件后验收。

## 普通阶段循环音乐 · normal-music

### 建议参数

- 类型：音乐；触发：进入云端普通阶段及奖励后下一段。
- 目标时长：60–90 秒。这是制作目标，不是已测量结果。
- 循环：是，无缝衔接，不用淡出掩盖接缝。
- 变体：1 条，每条独立文件；平台：平台无关。
- 输出：适合后续处理的干净 48 kHz WAV 母版；平台不能直接输出时后处理转换。运行格式在导入试听后确定。

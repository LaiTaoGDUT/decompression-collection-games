## 2. 待细化事项：不能当作已经冻结

### 玩法数值与边界

- 单局分数、结算统计、排行榜、永久成长是否存在。正式名称已冻结为“泡泡龙”，`gameId` 已冻结为 `bubble-shooter`。
- 棋盘精确行数、初始高度、危险线按球边缘还是格位判定、最大发射角与反弹次数、触控取消操作。
- 进度计算权重、需求量、清空棋盘补充规则；普通补行阈值、Boss 行动间隔和耐久/伤害。
- 道具在普通阶段的“有效消除”与补行计数细节，炸弹无目标等异常发射；免费刷新入口和替换颜色算法。
- 万能球多色择优规则、无可匹配颜色情况；炸弹半径；“清底两行”是最低占用行还是固定棋盘底行、稀疏布局范围，必须结合预览确认。
- 全部同色在轨道/变色后相连但不自动消除时，后续发射触发匹配的精确条件。
- Boss 补行和技能合并行动中，目标已消除、被移动或本次补行触线等顺序与预告一致性。
- 轨道到点、变色到点、普通补行、进度满、触线同时发生的统一结算优先级。已有顺序草案不能替代完整边界设计。
- 轨道与行偏移/边界的准确坐标算法，满轨道仍反向的预告反馈。
- 章鱼抓取上限达到后的动作、锚点数量和合法布局；防止长期不可解。
- 普通独立区域机制计数在复活后如何复位；广告恢复时状态锁、后台、重复点击处理。
- 无限难度上限/增长曲线、单次越过多个进度阈值如何处理。

## 0. 项目约束

### 视觉共用基线

- Cocos Creator 3.8.8、微信小游戏、竖屏 750×1334；预置图实际会被切成 3×3～6×6 网格。
- PZ1 色彩：深胡桃 `#4A2C20`、蜂蜜木 `#C9894B`、旧纸 `#F3E2BD`、松石绿 `#5B8A78`、砖红 `#A65C45`、炭墨 `#2D2520`、暖灰 `#8B7968`。
- 所有图片要求原创、无文字、无水印、无品牌、无可识别版权角色；图片内容要在 6×6 缩小后仍能辨认。
- 预置图需要清晰的大色块、明确的中心主体和中等细节密度；不要把棋盘线、方块边框、UI、标题或拼图网格画进图片。
- 禁止方向：大厅展柜皮肤、猫咪/水果纸雕、T48 霓虹电路、中国象棋书斋木雕、金属科幻、写实旧化脏污、复杂木纹、品牌包装和艺术家模仿。
- 动态中文由 Cocos `Label` 绘制，按钮、面板和状态卡优先用 `Graphics`、纯色 Sprite 或九宫格实现，不生成假中文 UI 图。

### 音频共用基线

- 独立声音身份：暖木敲击、纸卡摩擦、柔和机械滑轨、短促完成和弦；低密度、安静、适合长时间单手操作。
- 不使用 W1 的纸片水果音、T48 的电子脉冲/霓虹和弦、棋类落子音、版权旋律、品牌提示音、人声或可识别艺术家模仿。
- 音乐和音效均请求干净原创版本，后续保留 48 kHz WAV 母版，再按移动端需要制作运行时压缩版本。
- 外部平台：平台无关；实际生成时记录平台、模型、日期、完整提示词、输出 ID/URL、选用版本和许可条款。

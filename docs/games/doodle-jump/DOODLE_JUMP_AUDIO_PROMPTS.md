## 2. 独立声音身份：D1「稿纸桌面跃层」

声音要让玩家感觉自己在一张暖白稿纸上，用铅笔和彩笔控制一个纸片角色不断向上跳跃、投出纸飞机、躲避纸片危险物。它是轻快、清楚、略带手作感的休闲声音，不是软绒猫屋、硬木拼图、霓虹街机或科幻飞船。

- 核心关键词：轻快、干净、手绘、稿纸、铅笔、彩笔、纸卡回弹、桌面小敲击、向上、留白、长时间不疲劳。
- 主要材质：干燥石墨笔尖轻敲、铅笔在纸上的短摩擦、薄纸卡片的回弹、纸飞机掠过空气、很轻的木质桌面敲击、彩笔上行音阶。
- 能量曲线：普通落地和连续射击低刺激；强力道具和击杀更有上行感；危险预警先紧张但不吵；失败按原因收束；复活、里程碑和新纪录积极但不过度庆祝。
- 空间感：近场、居中、干净、短尾音，适合手机扬声器；不能依赖极低频、超宽立体声或长混响才能听清。
- 音乐行为：低密度原创器乐循环，使用稀疏铅笔节拍、纸张摩擦、木质小敲击和很短的彩笔音阶动机；不要有抢占射击和危险提示的主旋律。

必须和其他 Bundle 保持声音隔离：不复用大厅的画廊音乐，不复用《合成大胖橘》的软绒、猫咪、纸雕猫屋声音，不复用《霓虹 2048》的电子脉冲、合成器和街机声，不复用棋类游戏的木棋、墨刷、庄重铜玉声，也不把任何现有音频文件改名后当成《涂鸦跃层》正式音频。

## 3. 共用制作基线

- BGM 必须注明 `original instrumental game music`，默认无歌词、无人声、对白和完整流行歌曲结构。
- 除 BGM 外，每个文件只表达一个游戏事件；不要把多个 takes、多个事件或多个版本拼在一个文件里。
- 音效开头不要留空；瞬态要在手机小音量下清楚，尾音短而可控，不用长混响掩盖事件边界。
- 先保留干净的 48 kHz WAV 母版，再依据包体和手机扬声器听感制作运行时 MP3/OGG。外部平台的压缩预览不能直接视为候选发布文件。
- 平台不能保证精确采样率、循环点、干声或 stems 时，必须在人工后处理中完成裁切、去噪、循环对齐和格式转换。
- 高频重复音效优先生成 2–3 个听感相关但不相同的变体；变体通过微小的纸张摩擦、敲击位置和时间差区分，不要只改音量或简单升降调。
- 不预设未经项目确认的 LUFS 数值；最终按手机扬声器、BGM 与音效开关、连续触发、峰值和遮蔽情况人工调整。
- 所有素材的生成平台、模型或模式、生成日期、完整提示词、输出 ID/URL、选用版本、丢弃版本、许可条款和后处理步骤，都要在导入前记录。

## 4. 游戏内循环音乐：稿纸跃层循环

### 音频资产

- 文件：`dj-gameplay-loop-v1.mp3`
- 触发：游戏进入 `Playing` 后播放；暂停、前后台切换、失败和退出由公共音频服务暂停或停止。
- 类型：游戏内 BGM。
- 建议时长：45–60 秒。
- 循环：是；首尾节拍、和声、低频、纸张底噪和空间尾巴必须无缝衔接，不要突然淡出。
- 变体数量：1 条主循环；如果平台支持，可额外保留无主旋律版本或分轨版本。

### 建议参数

- 速度：约 92–104 BPM，节奏轻盈但不急迫，能够支撑自动弹跳和连续攀登。
- 和声：明亮、稳定、略有向上感；可以使用简洁的五声音阶或不复杂的三和弦循环，不要戏剧性转调。
- 节奏：铅笔轻敲和木质小敲击形成稀疏脉冲，纸张摩擦作为弱纹理，偶尔出现很短的彩笔上行音阶。
- 混音：中低密度、近场、居中；低频不能盖住黑洞和落地，持续高频不能遮挡纸飞机和 UFO 预警。
- 外部平台：平台无关。

## 12. 运行时接入与命名备注

### 12.1 Bundle 和路径

- 所有正式音频只进入 `game-doodle-jump` Bundle 的 `visual/audio/` 目录。
- 计划路径示例：`assets/games/doodle-jump/visual/audio/dj-gameplay-loop-v1.mp3`。
- 不得把《涂鸦跃层》音频放进 `assets/lobby/visual/audio/`，也不得放进其他小游戏的 `visual/audio/`。
- 外部平台压缩预览、来源不明的下载音频和未记录许可的临时文件只能放在项目外或开发占位目录，不能进入候选构建。

### 12.2 现有公共音频边界

当前项目提供 `AudioService`、`BundleAudioBank` 和 `FeedbackService`：

- `AudioService.playMusic()` 适合播放游戏内 BGM；暂停、前后台和退出应沿用公共生命周期。
- `AudioService.playEffect()`/`FeedbackService.play()` 适合短 one-shot。
- 当前公共 `FeedbackCue` 已包含 `uiButton`、`popup`、`toggle`、`collision`、`milestone`、`danger`、`failure`、`continue`、`record` 等通用语义。
- 纸飞机、平台状态、怪物、道具、UFO 和黑洞等专属 Cue 需要在《涂鸦跃层》实现时做游戏内映射；如果要扩展公共 `FeedbackCue` 类型，必须同时更新架构记录和兼容说明，不能在本提示词文档里偷偷改协议。
- `collision` 高频反馈继续遵守公共 80 ms 节流；射击 120 ms 冷却不是音效播放许可，不能让连续射击导致无限叠音。
- UFO 光束、黑洞吸引、Jetpack、Propeller Hat、Rocket 和 Shield 的持续循环素材是可选项。当前公共效果播放接口未提供显式循环状态管理，在运行时方案确定前不要把这些 WAV 标记为正式可导入。

### 12.3 事件与声音关系

| 玩法事件 | 音频处理 |
| --- | --- |
| 道具被碰到 | 立即播放对应激活音；不播放额外 pickup 音，不显示或朗读道具名称 |
| 道具持续生效 | 优先由 HUD 进度条表达；有独立循环通道后再启用可选 loop |
| 护盾激活 | 播放 `dj-item-shield-v1`；不显示数量和文字音效 |
| 护盾挡住危险 | 播放 `dj-shield-block-v1`，消耗护盾；不播放失败音 |
| 护盾结束 | 播放 `dj-shield-expire-v1`；不播放倒计时滴答 |
| 长按连续射击 | 纸飞机音效低量播放并受节流；不能遮挡危险提示 |
| 失败 | 失败事件首次锁定后只播放对应原因尾音一次，重复失败事件忽略 |
| 复活 | 复活成功并回到 `Playing` 后播放 `dj-resurrect-v1`，不是打开复活面板时播放 |
| 结算 | 先播放 `dj-result-sting-v1`；只有新纪录再追加 `dj-record-v1` |

## 13. 手动制作、来源和验收清单

每一条外部生成音频都要补充以下记录，提示词本身不能替代来源记录：

- 外部平台名称、模型或模式、生成日期；未知字段填写“待确认”。
- 完整复制实际使用的提示词，保存输出 ID 或 URL。
- 选中的 take、放弃的 take、人工剪辑版本和最终文件名。
- 适用许可条款、商业使用限制、是否允许修改和再分发；未确认许可不能进入候选构建。
- 后处理步骤：去噪、起始裁切、尾音裁切、循环点对齐、峰值检查、格式转换、压缩和导入参数。
- 最终文件所属 Bundle 和路径：`game-doodle-jump/visual/audio/`。

验收时至少检查：

- BGM 连续播放和暂停/恢复后没有跳变；退出游戏后没有残留音乐或音频实例。
- 普通落地、连续射击和怪物命中连续触发时没有爆音、刺耳高频或听觉疲劳。
- UFO 锁定、黑洞吸引和爆炸平台预警在 BGM 下仍然清楚；危险提示不能被纸飞机声覆盖。
- 五种失败尾音能听出不同原因，但都属于同一 D1 声音身份。
- 道具拾取即使用的声音时序正确；没有多余拾取气泡、倒计时、文字说明或护盾数量反馈。
- 无音频、关闭音效、关闭音乐、暂停、前后台切换、失败、复活、结算和退出状态都不会残留播放实例。
- Cocos 导入后检查采样率、压缩格式、循环属性、资源路径和 Bundle 依赖；未知来源或未验收文件保持开发占位状态。

## 14. 建议制作顺序

第一批先生成并试听最能验证核心手感的素材：

1. `dj-gameplay-loop-v1`。
2. `dj-land-1/2/3-v1`。
3. `dj-shot-paper-plane-v1`。
4. `dj-hit-light-v1`、`dj-hit-heavy-v1`、`dj-monster-kill-v1`。
5. `dj-item-spring-v1`、`dj-item-trampoline-v1`、`dj-item-shield-v1`。
6. `dj-ufo-lock-v1`、`dj-black-hole-pulse-v1`、`dj-platform-explode-warning-v1`。
7. `dj-ui-button-v1`、`dj-ui-panel-v1`、`dj-result-sting-v1`。
8. 五条失败尾音、`dj-resurrect-v1`、`dj-milestone-v1`、`dj-record-v1`。

## 2. 独立声音身份：T48-N1「霓虹数字电路」

2048 的画面是深色竖向电路舱体、蓝紫霓虹边框、青色细线、洋红发光和数字棋子升级。2048 棋子使用金色能量质感，4096 使用高亮品红；声音应让玩家感到自己在一个干净、专注、会逐级增能的数字电路空间中整理能量方块。

- **核心气质**：清晰、克制、聪明、满足、带轻微街机感，但不是喧闹的街机厅。
- **主要材质**：短促合成脉冲、干净数字 click、窄带 FM/相位调制音、玻璃般的数字亮点、柔和的中低频能量 thump、很短的 gated noise。
- **色彩映射**：青蓝对应普通移动和基础合成；紫色/洋红对应连锁与高阶能量；金色对应 2048/4096 目标；低沉蓝紫对应危险状态和游戏结束。
- **空间与混音**：音效近场、居中、干净、短尾；音乐可以有克制的窄幅立体声，但不要依赖超宽声场、极低频或长混响才能成立。
- **音乐行为**：低到中等密度的原创器乐电子循环，保留操作空隙，不用突出主旋律，不做完整流行歌曲结构。
- **反馈层级**：移动最轻，单次合成更亮，连锁更密，高阶合成更有能量，目标和新纪录必须各自独立；危险音乐增加压力但不变成警报。

禁止把其他 Bundle 的声音身份带入 2048：不要使用木质棋盘、木片滑槽、纸雕猫咪、水果碰撞、真实猫叫、墨刷、铜玉棋子或大厅展柜音色。也不要使用真实警报器、警笛、枪械、爆炸、恐怖氛围、品牌提示音、版权旋律、现成游戏音效或对任何可识别艺术家、品牌和作品的模仿。

## 3. 共用制作基线

- 两条 BGM 都是原创 instrumental game music；默认无歌词、无人声、对白、口哨和完整歌曲段落。
- 两条 BGM 建议保持相同拍号、速度和主音中心，便于危险状态切换时保持同一游戏身份；危险循环通过密度、低频脉冲和和声张力提升压力，而不是突然换成另一种音乐。
- BGM 目标时长约 45–60 秒，首尾做成真正可无缝循环的完整段落。循环点的节拍、和声、低频、噪声纹理和空间尾巴必须连续，不要突然淡出。
- 音效全部是独立 one-shot；开头不要留空，主要瞬态应在手机小音量下仍然清楚，尾音要短而可控。
- 高频重复音效不要加入长混响、持续高频振铃或过强低频；音效需要和音乐同时播放而不互相遮蔽。
- 建议先保留干净的 48 kHz WAV 母版，再根据微信小游戏包体和手机扬声器听感制作运行时 MP3。外部平台压缩预览不直接视为最终候选文件。
- 生成结果不得把多个 takes、多个事件或多个音效变体塞进同一个文件；每个运行时文件只表达一个明确的音乐段落或事件。
- 下面的时长是生成和剪辑建议，不代表当前旧文件的实测时长。

# 《无尽剑域》竖屏无尽割草 Roguelike 游戏策划案 V1.0

> 文档状态：**开发锁定版**  
> 游戏类型：竖屏 / 无尽生存 / Roguelike / 自动战斗 / 单手操作  
> GAME_ID：`endless-sword`  
> Asset Bundle：`game-endless-sword`  
> 屏幕方向：竖屏  
> 核心目标：**尽可能生存更长时间，并不断突破更高天劫重数。**


项目 Runtime 的具体方法名必须在实施前读取现有仓库后进行适配，不凭空创造新的大厅接口；但游戏内部规则、数据和资源按照本文直接实现。

---

# 1. 游戏定位

## 1.1 游戏名称

**无尽剑域**

英文内部名：

`Endless Sword Domain`

## 1.2 核心体验

玩家操控一名修士，在不断涌来的妖魔中移动。

角色自动释放：

- 飞剑
- 剑阵
- 雷法
- 火法
- 冰法
- 法印
- 飞针
- 葫芦
- 星陨
- 风刃
- 太极灵珠

击杀敌人获得经验，不断升级形成 Build。

游戏不存在最终通关。

游戏最终结果只有：

> **你能活多久。**

---

# 2. 四个核心设计支柱

## 2.1 单手移动

玩家只负责：

> 移动 + 躲避 + 抢资源

所有攻击自动进行。

---

## 2.2 Build 成型

一局经历：

`普通技能`

↓

`Lv5`

↓

`满足对应心法`

↓

`Boss 宝箱`

↓

`技能进化`

↓

`玄境无限强化`

因此即使游戏进行 30～60 分钟，升级依然不会失去意义。

---

## 2.3 无尽灾厄

15 分钟后开启真正的无尽阶段。

敌人不断获得永久灾厄强化：

- 数量
- 血量
- 速度
- 伤害
- 死亡爆炸
- 精英化

游戏最终会自然超过玩家 Build 的承受能力。

---

## 2.4 天机灵珠

每隔固定时间，在玩家附近出现一个需要主动移动获取的：

**天机灵珠**

获得后立即触发强力场景效果。

这套系统负责打破传统割草游戏：

> 一直绕圈就能玩的问题。

玩家需要判断：

> 是否冒险穿过怪群抢灵珠。

# 4. 游戏状态

游戏内部状态固定为：

```typescript
type RunState =
  | 'idle'
  | 'ready'
  | 'playing'
  | 'levelup'
  | 'paused'
  | 'reviveOffer'
  | 'completed'
  | 'disposed';
```

## idle

游戏对象已经创建，但资源尚未完全初始化。

## ready

资源、场景、HUD 均已创建，可以开始。

## playing

正常游戏。

## levelup

升级三选一。

游戏时间完全暂停。

## paused

用户主动暂停。

## reviveOffer

玩家死亡，等待：

- 广告复活
- 结束游戏

底层 Gameplay 完全停止。

## completed

本局彻底结束。

## disposed

所有资源引用和节点清理完成。

# 5. 游戏时间

所有刷怪、Boss、技能、灾厄等全部基于：

```typescript
gameplayElapsedTime
```

只有：

`state === playing`

时增长。

以下时间完全不计入游戏时间：

- Pause
- Level Up
- 广告播放
- Result
- App 切后台

# 6. 操作方式

## 6.1 移动

采用：

**浮动虚拟摇杆。**

玩家在游戏区域按下手指：

当前位置成为摇杆中心。

拖动决定移动方向。

松手：

角色停止。

---

## 6.2 摇杆参数

```typescript
JOYSTICK_RADIUS = 88
JOYSTICK_DEAD_ZONE = 12
```

移动速度根据拖动距离线性变化。

```text
0～12 px
不移动

12～88 px
0%～100% 移速

>88 px
100% 移速
```

## Boss 天道宝箱规则

掉落位置：

```text
Boss 死亡位置
```

存在时间：

```text
30 秒
```

到期未拾取：

```text
自动飞向玩家并被拾取
```

主动拾取半径：

```text
120
```

拾取时：

```text
可进化技能 ≥ 2：
暂停游戏（同升级界面），展示最多三个可进化技能，选择一个

可进化技能 = 1：
直接进化，全屏提示
```

无可进化技能时：

```text
不刷新宝箱
Boss 死亡基础奖励（回血 / 分数）照常发放
```

多 Boss 同场：

```text
每只 Boss 独立掉落一个宝箱
各自独立触发一次进化选择

场上同时最多 2 个宝箱
第 3 个宝箱出现时
最早的未拾取宝箱立即自动飞向玩家
```

# 136. V1.0 最终玩法定义

《无尽剑域》的最终核心可以概括为：

> **玩家单手操控一名修士，在无限剑域中移动生存，依靠自动御剑与各种术法持续击杀妖魔，通过升级三选一形成 Build。普通技能达到 Lv5 并搭配对应心法后，可利用每五分钟出现的天劫 Boss 完成技能进化。15 分钟后，世界进入无限灾厄阶段，怪物数量、速度、生命、伤害和特殊机制不断增强。玩家通过进化技能、玄境无限强化、境界突破以及冒险抢夺天机灵珠继续提升战斗力，直到最终被不断强化的妖潮击败。游戏没有最终胜利，唯一目标是突破自己的最高分、生存时间和天劫重数。**

这就是 V1.0 的完整产品基线。

## 1. 原创方法

全部波形由 `tools/audio/generate-original-audio.js` 直接合成，没有下载、采样、拼接或模仿外部音乐/音效。固定随机种子为 `0x51A7E202`，采样率 48 kHz，母带为双声道 16-bit PCM WAV。脚本使用正弦/三角/拨弦谐波、确定性过滤噪声、独立包络、声像和纸片节奏构造声音。

运行文件由未修改的开发依赖 `lamejs 1.2.1` 离线编码：音乐 96 kbps、音效 64 kbps MP3。该工具声明 LGPL-3.0，仅在开发阶段使用，不进入游戏 Bundle；致谢与使用方式见仓库根目录 `THIRD_PARTY_NOTICES.md`。

## 2. 两套独立方向

### L1 柔光收藏馆

- 32 秒循环音乐：缓慢正弦和弦、克制金属点音、极轻空间颗粒；V2 在原基底上新增温暖低频托底、回应旋律和稀疏空间闪光，目标近似 -20 LUFS。
- 独立音效：大厅按钮、设置弹窗、开关切换。
- 文件只位于 `assets/lobby/visual/audio/`，不包含纸张、纸箱或游戏连锁音色。

### W1 纸片折纸果摊

- 32 秒循环音乐：在纸片拨弦与夏日五声音阶上增加双循环和声、轻量低音托底、交替回应旋律与稀疏纸片闪光；目标近似 -23 LUFS，整体更轻且层次更完整。
- 独立音效：游戏按钮、投放、3 个碰撞变体、折叠、合成、连锁、危险、失败、续玩、新纪录。
- V2 定向修改：危险音效由单一低频提示改为 1.05 秒四段警报脉冲、上扬扫频与加速紧迫底层；失败音效完全移除旧低沉合成器方案，改为 1.2 秒纸片散落、三段下行音高和克制低落收尾。
- V3 定向修改：W1 循环由 24 秒扩展至 32 秒并降低到近似 -23 LUFS；三组碰撞 Cue 缩短为 0.10 / 0.11 / 0.12 秒，采用更平滑的纸面噪声与克制正弦主体，目标近似 -24 LUFS、峰值上限 -8 dBFS，降低连续碰撞的吵闹感。
- V4 定向修改：投放松手 Cue 移除 92 Hz 低频三角波闷砸声，改为 0.15 秒的柔和纸面滑动、下行正弦轻响与极轻高频收尾；目标近似 -22 LUFS、峰值上限 -8 dBFS。
- 文件只位于 `assets/games/watermelon/visual/audio/`，不复用 L1 文件名、音乐或正式音效。

## 3. 接入与生命周期

- `BundleAudioBank` 从当前 Bundle 加载音乐和 Cue，在场景销毁时停止音乐、取消 Cue 注册并释放服务侧引用。
- 大厅按钮、设置弹窗和切换开关使用 L1 Cue；游戏 HUD、投放、碰撞、合成、连锁、危险、失败、续玩和纪录使用 W1 Cue。
- 音乐/音效开关继续由 `AudioService` 和版本化设置控制，即时生效。
- 主动暂停和失败冻结暂停游戏音乐；继续、重开恢复；切后台与前台使用独立暂停原因，避免重复播放；退出/Bundle 释放停止音乐。
- 碰撞使用 3 个轮换变体，80ms 内重复请求被节流，播放音量为 0.62；其他反馈不受该节流影响。
- 振动映射：按钮/投放/切换为 light，折叠/合成/连锁为 medium，里程碑/失败/新纪录为 heavy；Web 或不支持平台禁用。

## 4. 质量与包体

- 文件数：17 WAV 母带 + 17 MP3 运行文件。
- 运行文件总大小：830,400 bytes。
- 两首母带循环起点 0、终点均为 1,536,000 sample，边界采样差均为 0。
- 峰值均不高于 -2 dBFS；大厅音乐近似 -20 LUFS、W1 音乐近似 -23 LUFS；普通音效目标近似 -15 LUFS，投放松手音效近似 -22 LUFS，三组碰撞音效近似 -24 LUFS。
- 此处响度为脚本记录的全文件 RMS 近似值，不冒充 BS.1770 专业仪表测量。
- Creator 抽查 L1 音乐、W1 音乐与碰撞音效均导入为 `cc.AudioClip`。

验证输出：`assets=17, wav=RIFF/48kHz, mp3=valid, music_seams=0, peaks<=-2dBFS, bundle_routes=isolated, runtime_bytes=830400`；`music_pause_layers=passed, collision_throttle=80ms, variants=1-2-3, unregister=passed`。

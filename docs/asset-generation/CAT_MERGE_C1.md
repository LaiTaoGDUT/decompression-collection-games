## 4. 动画与物理边界

`FruitBody` 的类名与圆形物理配置继续保留，以避免破坏序列化和存档兼容。运行时视觉节点改为 `CatVisual`：

- 待机：轻微呼吸缩放与左右摆动，不同等级使用不同节奏和方向。
- 投放：先纵向拉伸，再横向压缩并回弹。
- 碰撞：圆形内部产生压扁、反向拉伸和回正。
- 合成：由小到大弹出，随后自动进入待机循环。
- 暂停：停止内部 Tween；恢复时重新进入待机循环。

上述动画只作用于内部 Sprite；`CircleCollider2D`、节点尺寸、危险线和合成半径始终保持正圆且不缩放。

## 5. ImageGen 提示摘要

猫咪母版提示要求精确 4×3 网格、11 只不同花色圆猫、最后一格为空、最终级为极胖橘猫、纯绿色键控背景、无文字和外部阴影。背景提示要求 9:16 猫咪屋、中央 70% 低细节留白、边缘猫爬架与毛线球。封面提示要求 4:3、胖橘居中、低等级猫环绕、无文字与 UI。

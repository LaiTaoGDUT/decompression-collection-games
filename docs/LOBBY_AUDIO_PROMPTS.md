## 2. 独立声音身份：L1「阳光糖果街机云端」

大厅视觉由暖珊瑚橙、奶油金色光束、白色高光、明亮蓝色和少量红黄色组成，画面有圆润的游戏手柄、云朵和星光装饰。声音要表现“轻松浏览一组小游戏”的欢迎感，而不是某一款具体游戏的玩法反馈。

- 核心关键词：阳光、轻盈、圆润、糖果塑料、透明亮点、云朵空气感、亲切、低压力。
- 主要材质：圆润的软胶/塑料玩具触感、透明糖果玻璃的短促亮点、柔软气泡 pop、温暖空气垫和很轻的手掌节拍。
- 情绪曲线：进入大厅时欢迎，浏览卡片时轻快，打开设置时柔和展开，切换开关时清楚而克制；不能制造竞争、危险或失败情绪。
- 空间与混音：近场、居中、干净，依靠中频和清晰瞬态在手机扬声器上可辨识；只保留很短的空气感，不使用大房间混响。
- 禁止方向：不要使用滑块拼图的硬木/纸卡、合成大西瓜的软绒纸雕、2048 的霓虹电子脉冲、象棋的木棋子/墨刷/铜玉质感，也不要使用金属科幻、真实投币机、老虎机硬币声、真实环境录音、品牌提示音或可识别旋律。

## 3. 共用制作基线

- 音乐必须是原创 instrumental game music；默认无歌词、无人声、对白和完整流行歌曲结构。
- 除 BGM 外，每个文件都是独立 one-shot，只表达一个事件；不要把多个 takes、多个事件或开关开/关两个版本拼在同一个文件中。
- 所有音效开头不要留空，瞬态要在手机低音量下仍然清楚，尾音短而可控；不要依赖长混响制造“高级感”。
- 建议先保留干净的 48 kHz WAV 母版，再按包体和手机扬声器听感制作运行时 MP3。外部平台的压缩预览不直接作为候选发布文件。
- 若平台不能保证精确采样率、干声或循环点，需在外部 DAW 中完成裁切、去噪、循环对齐和格式转换。
- 生成后记录平台/模型、生成日期、完整提示词、输出 ID 或 URL、选用与淘汰版本、许可条款和后处理步骤，并与最终文件一起保留。

## 4. 大厅循环音乐：阳光浏览空间

### 音频资产

- 文件：`l1-gallery-loop-v1.mp3`
- 触发：大厅 `LobbyEntry` 初始化音频银行后开始播放；`AudioService` 负责音乐开关、前后台暂停和进入小游戏时的停止。
- 类型：大厅 BGM。
- 建议时长：45–60 秒；比当前约 32 秒的版本更不容易在大厅长时间浏览时产生明显重复。
- 循环：是；首尾节拍、和声、低频、空气感和尾部空间必须自然衔接，不要突然淡出。
- 声音身份：L1「阳光糖果街机云端」；透明糖果质感、圆润玩具触感、暖空气和星光亮点。
- 变体数量：1 条主循环；如平台支持，可额外保留不带主旋律的简洁版本或 stems，但运行时先选用 1 条。

### 建议参数

- 类型：音乐 / 大厅循环。
- 用途与触发事件：玩家在大厅浏览游戏卡片、打开或关闭设置面板时持续播放。
- 时长：45–60 秒；建议约 84–92 BPM，节奏稀疏而有轻微律动。
- 循环：是；不要使用淡入淡出作为循环边界，循环点处的拍点与和声必须可直接相接。
- 声音身份：明亮大调或轻五声音阶、透明糖果拨片、圆润玩具合成器、柔软空气垫和极少量轻手掌节拍。
- 建议输出：干净 instrumental mix；如平台支持，再提供无主旋律版本或 stems。
- 变体数量：1 条正式运行版本。
- 外部平台：平台无关。

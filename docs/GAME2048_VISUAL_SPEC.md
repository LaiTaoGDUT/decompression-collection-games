# 霓虹 2048 视觉与反馈规格

> 方向：T48 深靛霓虹电路
> 设计基准：750×1334 竖屏
> 目标：与“合成大胖橘”的暖色纸片猫屋形成清晰区隔

## 1. 视觉语言

- 背景使用用户提供的深靛电路场景图，运行时只保留极轻的可读性遮罩，不再叠加旧版网格氛围层。
- 棋盘使用用户提供的 4×4 棋盘图；数字块直接使用用户提供的 12 张霓虹棋子图，蓝、青、绿、黄、橙、红、紫、金、品红按图片本身的颜色逐级区分。512 及以上棋子沿用各自的静态图，不增加常驻高阶材质或特殊视觉层。
- 标题使用用户提供的“霓虹2048” Logo，HUD 和暂停保持明亮的硬边电子面板语义，避免无功能副文案分散注意力。
- 暂停、目标和结果面板延续本游戏的电路框线与棋子同色系按钮，不套用大厅或猫咪游戏弹窗皮肤；常驻操作区只保留暂停，不提供撤销。

常驻视觉以深靛背景为底，标题、棋盘和棋子由正式图片承担主要霓虹；白色只用于文字，不使用全屏闪光或持续亮度脉冲，确保长时间游玩舒适。

## 2. 布局与适配

- 顶部为标题与操作区，中部为分数/最高分和 4×4 棋盘，底部只保留滑动提示，不展示品牌尾注。
- 标题、分数和暂停按钮按屏幕可见宽度布局，不额外扣除左右系统安全区；暂停按钮右缘与屏幕右缘对齐，右侧不绘制边框和圆角。棋盘继续使用设计坐标并保持自身边距，背景四周保留 32 设计像素出血，覆盖 Creator 预览画布的边缘采样区。
- 触控滑动在棋盘和主画布范围均有效；关键按钮保持独立间距和清晰按压反馈。

## 3. 动效与声音映射

- 有效移动逐块沿真实格子轨迹滑至目标位置；新数字在滑动完成后缩放出现；合并数字在汇聚完成后使用克制的脉冲并同步分数刷新。128 及以上合成按等级递增光环层数、扩散尺寸、亮度和冲击缩放，并按 128、256、512、1024、2048、4096 六档叠加晶体、连击与里程碑音色；2048 和 4096 合成特效播放完成后稍作延迟，再复用同一套“恭喜你”庆祝层。
- 512 及以上棋子不使用常驻轮廓光、呼吸脉冲或特殊视觉层；合成瞬间的高阶光环、冲击缩放和芯核特效仍然保留。
- 空格不多于 2 格且本局仍可继续时，启用洋红边缘警报、全屏扫描线与“空间临界”状态提示；空格恢复到 3 格后自动退出。
- 无效移动只给克制反馈，不生成新块；目标与失败使用独立全屏冻结层。
- 首次达成 4096 显示一次终极庆祝层并锁定输入；庆祝层提供“继续冲击更高纪录”“完成本局”“返回大厅”三个安全出口，继续后本局仍可挑战更高数字且不重复弹出。
- 声音采用电子脉冲、玻璃感正弦和和弦层，不复用 W1 纸片音色。Cue 包含按钮、移动、无效移动、生成、合并、连锁、目标、失败和新纪录。

## 4. 用户提供素材接线

- 大厅封面使用用户提供的 `封面.png`；物理文件只位于 `lobby` Bundle，游戏 Bundle 不反向引用大厅资源。
- 游戏背景、标题 Logo、棋盘和棋子使用用户提供的对应 PNG；棋子集合按 4×3 等分为 12 张 362×362 运行图，标题与棋子外部纯黑边离线转透明。
- 原始文件归档：`art_sources/game2048/user-provided-v1/`；运行文件分别位于 `assets/lobby/visual/covers/game2048/` 与 `assets/games/twenty48/visual/`。
- 图片来源与使用依据：用户提供并明确要求用于本项目；核对日期：2026-08-18。

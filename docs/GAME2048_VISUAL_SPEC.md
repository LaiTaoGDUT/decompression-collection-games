# 霓光 2048 视觉与反馈规格

> 方向：T48 深靛霓光电路  
> 设计基准：750×1334 竖屏  
> 目标：与“合成大胖橘”的暖色纸片猫屋形成清晰区隔

## 1. 视觉语言

- 背景使用深靛黑与低对比电路网格，辅以青绿、紫色和琥珀色环境光；环境光采用大面积低透明度色池与稀疏节点，不使用闪烁或呼吸动画。
- 棋盘使用中深色槽位与多层细霓光边框；数字块以蓝、紫、青绿、翠绿、黄绿、琥珀、橙红和品红逐级拉开色相与明度，保证相邻等级可以快速区分，同时避免大面积高亮纯色造成视觉疲劳。
- 标题只保留 `NEON 2048` 主信息，HUD 和暂停保持硬边电子面板语义，避免无功能副文案分散注意力。
- 暂停、目标和结果面板延续本游戏的电路框线与青绿/琥珀按钮，不套用大厅或猫咪游戏弹窗皮肤；常驻操作区只保留暂停，不提供撤销。

常驻视觉以暗部为主，仅标题字缘、棋盘边框和数字块轮廓使用中低强度霓光；白色只用于文字，不使用全屏闪光或持续亮度脉冲，确保长时间游玩舒适。

## 2. 布局与适配

- 顶部为标题与操作区，中部为分数/最高分和 4×4 棋盘，底部只保留滑动提示，不展示品牌尾注。
- 棋盘和 HUD 使用设计坐标布局；棋盘在窄屏下左右至少保留约 54 设计像素视觉安全区，背景四周保留 32 设计像素出血，覆盖 Creator 预览画布的边缘采样区。
- 触控滑动在棋盘和主画布范围均有效；关键按钮保持独立间距和清晰按压反馈。

## 3. 动效与声音映射

- 有效移动逐块沿真实格子轨迹滑至目标位置；新数字在滑动完成后缩放出现；合并数字在汇聚完成后使用更明显的脉冲并同步分数刷新。128 及以上合成按等级递增光环层数、扩散尺寸、亮度和冲击缩放，并按 128、256、512、1024、2048 五档叠加晶体、连击与里程碑音色。
- 512 及以上棋子增加常驻的多层轮廓光与呼吸脉冲；512、1024、2048 的层数、亮度和呼吸幅度逐级增强。
- 空格不多于 2 格且本局仍可继续时，启用洋红边缘警报、全屏扫描线与“空间临界”状态提示；空格恢复到 3 格后自动退出。
- 无效移动只给克制反馈，不生成新块；目标与失败使用独立全屏冻结层。
- 声音采用电子脉冲、玻璃感正弦和和弦层，不复用 W1 纸片音色。Cue 包含按钮、移动、无效移动、生成、合并、连锁、目标、失败和新纪录。

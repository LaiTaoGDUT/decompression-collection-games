## 2. 独立声音身份：SW1「玄青剑域」

画面是暗色玄幻战场：玄青石地、妖魔成群、高饱和法术剑光。声音要让玩家感到“御剑破阵”的锐利与爽快，而不是安静解压或机械电子。

- 核心关键词：锐利、剑鸣、法术爆发、战鼓驱动、东方玄幻、割草爽感、短促干净。
- 主要材质：金属剑刃的清吟与破空、雷电磁爆的脆响、冰晶凝结的细碎声、火焰的低吼、古筝与琵琶的快速拨扫、中国大鼓与低频电子骨架。
- 能量曲线：普通攻击轻而快；技能法术有明确爆发；精英/Boss 出场用低频压迫；升级与进化是明亮的正向反馈；死亡与灾厄是沉重的负向警示。
- 空间与混响：近场、居中、干净为主，尾音短；适合手机扬声器，不能依赖低音炮或宽立体声才听得见。
- 禁止方向：2048 的霓虹电子脉冲与合成和弦、猫咪游戏的软绒纸片水果音、象棋的木棋子与墨玉声、拼图的木框纸卡声、版权旋律、品牌提示音、人声、对白、可识别艺术家模仿。

## 3. 共用制作基线

- BGM 请求原创 instrumental game music：无歌词、无人声、无对白、无完整主歌副歌结构；旋律动机克制，不抢操作反馈。
- 所有 SFX 均为独立 one-shot：单文件单事件，开头不留空，结尾不长混响拖尾。
- 高频事件（enemyHit/enemyDie/xpPickup/swordHit）按变体组生成，变体之间听感相关但微观时值与质感不同，供运行时轮换，避免重复疲劳。
- 目标导出：48 kHz WAV 干净母版入库，运行时再按需压缩为 mp3；外部平台的压缩预览不算最终文件。
- 外部平台：平台无关；实际生成时逐条记录平台、模型、日期、完整提示词、输出 ID/URL 与许可条款。

## 15. 手动验收清单

每条音频生成后：

1. 记录平台、模型/工具、日期、完整提示词、输出 ID/URL、许可条款，并与最终音频交付物一起保留。
2. 试听检查：单事件、无水印、无平台提示音、开头无空白、结尾无多余长尾。
3. BGM 做循环拼接试听（首尾相接循环 3 遍），接缝无鼓点错位、无电平跳变。
4. 高频音效（enemyHit/enemyDie/xpPickup/swordHit）在 10 次/秒密度下试听 10 秒，无疲劳感、无削波。
5. 与两首 BGM 同放试听，检查频段掩蔽；必要时对 SFX 做轻量化处理。
6. 48 kHz WAV 母版入库后再压缩运行时 mp3，记录后处理（裁切/归一/转换）设置。
7. 通过 `AudioService` 接入后，在暂停/恢复/切后台/退出全流程检查无残留播放。

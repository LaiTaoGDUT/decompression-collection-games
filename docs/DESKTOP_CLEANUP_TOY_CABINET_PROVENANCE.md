# 桌面大清理：童年玩具柜素材溯源

## 源文件

- 暂存文件：`art_sources/桌面大清理/主题-童年玩具柜/desktop-cleanup-toy-cabinet-source-v2.png`
- 提供方：用户在 2026-08-25 提供的新 PNG（由用户自行生成并确认可用于本项目）。
- 外部来源：无；本项目未从第三方网站下载素材。
- 当前原始规格：1024×1536，RGBA，透明背景；背景区域 Alpha 为 0。
- 当前主题注册目录暂不启用玩具柜；两版源图仅作为用户提供的原始参考暂存。

## 固定顺序

图集按从左到右、从上到下排列，运行时 ID 与图像格一一对应：

1. 木积木、魔方、陀螺、溜溜球
2. 发条机器人、玩具小车、拼图块、弹珠袋
3. 纸风车、玩具喇叭、玩具鼓、毛绒小熊
4. 玩具望远镜、摇铃、发条钥匙、纸飞机
5. 套圈玩具、手指滑板、小恐龙、星星奖章

## 构建记录

曾使用 `tools/build-desktop-cleanup-toy-cabinet-assets.py` 按 Alpha 连通主体识别 20 个玩具，并生成 4×5、单格 384×384 的 RGBA 图集和命中掩码；命中多边形由 `tools/generate-desktop-cleanup-hit-polygons.py` 离线生成。生成的运行时图集、掩码和命中脚本已按需求删除；如未来重新启用该主题，需要从源图重新生成。

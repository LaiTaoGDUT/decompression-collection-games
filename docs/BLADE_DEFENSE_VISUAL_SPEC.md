# 转刀塔防视觉与交互规格（BD2）

> 主题：春日萌宠守卫  
> 目标：重做为明亮、Q萌、手绘动漫卡通风格，并在小屏竖屏设备上优先保证路线、拖放目标和头顶数字可读。

## 1. 视觉方向

- 独立使用“浅绿草地 + 奶油沙路 + 珊瑚红 + 天空蓝”的 BD2 皮肤，不复用 2048 的深色霓虹面板。
- 角色采用圆润比例、深棕粗描边、简化赛璐璐明暗和夸张表情；参考图只用于抽取视觉语言，不复刻其角色、界面或构图。
- 背景、圆环棋盘、大厅封面均使用独立插画；运行态热点、数字与状态描边仍由 Cocos 原生组件实现，确保适配和清晰度。

| Token | 色值 | 用途 |
|---|---|---|
| `bd2.grass` | `#ABD85B` | 草地、战场主体 |
| `bd2.sand` | `#F7D371` | 怪物圆环路线 |
| `bd2.ink` | `#563A26` | 轮廓、正文、高对比描边 |
| `bd2.cream` | `#FFF8DA` | HUD、弹层、操作提示 |
| `bd2.sky` | `#5CC2EA` | 移动、合法目标 |
| `bd2.coral` | `#FF7468` | 生命、危险、失败 |
| `bd2.gold` | `#FFBF3E` | 合成、宝箱、奖励 |
| `bd2.lavender` | `#A676DC` | Bonus、稀有反馈 |

## 2. 响应式布局

- 参考画布 750×1334，但尺寸必须取 Canvas 与 `view.getVisibleSize()` 的实际交集；不得用大于视口的硬编码最小宽高。
- 安全布局从上到下为：标题/暂停、四项紧凑 HUD、最大化圆形战场、底部单行操作提示。
- 棋盘直径始终小于 `视口宽度 - 24`，同时受顶部和底部保留区限制；320×568 起不应发生横向或纵向裁切。
- 12 个固定塔位全部在路线内侧环形分布，宠物主体不越过路线；怪物、宝箱只沿外圈移动。

## 3. 头顶数值

- 宠物头顶只显示当前攻击力数字，不显示“Lv.”、“伤害”等重复文字。
- 怪物与宝箱头顶只显示向上取整后的剩余血量数字，不显示 `当前/最大`，不额外显示常驻血条。
- 终点木门头顶只显示当前剩余生命数字。
- 三类数字统一使用白色或奖励金色字形、4～5 px 深棕描边，始终压在角色、武器和特效上层。

## 4. 宠物、怪物与武器

- 首批实装两只宠物：Lv.1 叶领小狗、Lv.2 探险小猫；两只均有 4 帧循环待机/跑动素材。
- 首批实装两只怪物：萝卜小恶魔、橡果野猪；按波次交替使用，各有 4 帧行走素材。
- Lv.1 专属胡萝卜短刀，1 把同时旋转；Lv.2 专属鱼形回旋刃，2 把同时旋转。
- Lv.3～Lv.8 在后续角色批次完成前使用颜色与轮廓各异的矢量武器占位；武器数量始终严格等于宠物等级，伤害与转速来自模型。
- 所有帧使用 256×256、脚底居中、共享缩放的透明 PNG；切帧时角色占位不得跳动。

## 5. 拖放状态

- 使用全局触摸监听，开始点仍必须命中棋盘内宠物；拖出棋盘或经过其他 UI 时不能丢失移动/结束事件。
- 可触摸半径不小于 44 设计单位；拖动宠物半透明跟手，攻击力数字与专属武器共同跟随。
- 空位显示天空蓝目标环；异级宠物显示交换目标；同级宠物显示金色合成目标；无效落点回弹且不改变模型。
- 触摸取消、暂停、切后台、结算和重建布局时立即清理拖动状态。

## 6. HUD 与弹层

- HUD 保留生命、波次、分数、最高分四项，使用奶油胶囊卡片与彩色圆点，不使用 2048 的深色霓虹卡。
- 底部常驻区只保留拖动说明与当前宠物摘要；队列信息仅在存在待领取宠物时通过提示文案反馈，不挤压战场。
- 暂停、Bonus、结算改用奶油色卡通面板、深棕轮廓和暖色按钮；禁止出现“MOON GARDEN”等旧主题文字。

## 8. 验收

- 320×568、375×667、390×844、750×1334、750×1624 下，标题、HUD、圆盘、提示区及暂停按钮全部在屏内。
- 从任意已占塔位拖到空位可移动，拖到异级可交换，拖到同级可合成；拖动中途移出棋盘仍能正常收尾。
- 宠物、怪物、宝箱、终点只显示对应的头顶数字；不出现旧的双行属性标签或 `当前/最大` 血量。
- Lv.1/Lv.2 使用不同角色、不同武器，武器数量分别为 1/2；四帧动画无缩放跳变。
- 大厅封面、背景、棋盘、HUD、弹层和按钮在同一套春日卡通视觉语言内，不残留 2048 或 BD1 月夜皮肤。

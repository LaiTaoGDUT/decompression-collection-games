# 《棋逢对手·无尽挑战》完整游戏玩法方案 V1.0

## 1. 游戏概述

《棋逢对手·无尽挑战》是一款基于中国象棋棋子移动规则改造的：

**单棋子 + 回合制 + 策略生存 + 无尽挑战游戏。**

玩家整局游戏始终只控制：

# 「车」×1

敌方棋盘中会不断出现：

- 卒
- 士
- 象
- 马
- 炮
- 车
- 将

玩家需要利用「车」横竖移动的特点，在持续增加的敌棋中：

- 寻找安全位置
- 吃掉敌棋
- 制造多重威胁
- 逼迫关键敌棋移动
- 控制敌方唯一一次行动
- 击杀将军
- 使用道具化解危险局面
- 尽可能生存更久
- 获得更高分数

游戏：

**没有关卡终点。**

玩家死亡且不再复活时：

**本局结束。**

---

# 2. 核心游戏体验

玩家初期考虑的是：

> 我现在可以吃哪个棋？

熟悉之后变成：

> 我走到这里，对方下一步会走谁？

进一步变成：

> 我同时威胁马、炮和卒，对方只能救一个。

高手需要考虑：

> 我不是在控制自己的车，而是在利用自己的车决定敌人的下一步行动。

因此整个游戏最核心的策略不是：

**追着敌棋吃。**

而是：

# 利用多重威胁操纵敌方唯一一次行动。

---

# 3. 棋盘

采用：

# 9列 × 10行

共：

**90个棋位。**

视觉上可以保留中国象棋棋盘风格。

但玩法不区分：

- 楚河汉界
- 红方区域
- 黑方区域
- 九宫限制

整个棋盘均可以正常使用。

- 血量成长

# 6. 玩家车移动规则

玩家车可以：

**横向或纵向移动任意格。**

不能：

- 斜向移动
- 穿过任何棋子

例如：

```text
    ↑
    ↑
← ← 车 → →
    ↓
    ↓
```

---

# 7. 玩家吃子

如果某方向上第一个遇到的棋子是敌棋：

玩家可以直接移动到该位置。

目标敌棋：

# 被击杀。

例如：

```text
车 □ □ 马
```

玩家可以：

```text
车 → → → 马
```

击杀马。

但是：

```text
车 □ 卒 □ 马
```

因为卒挡在前方：

玩家不能直接吃马。

---

# 8. 玩家不能停在原地

正常玩家行动：

# 必须完成一次移动。

玩家不能通过：

“什么都不做”

主动跳过自己的回合。

使用道具：

也不会替代正常移动。

# 14. 炮

## 普通移动

与车相同：

横向或纵向移动任意距离。

不能穿过棋子。

## 吃玩家

炮与玩家之间：

必须恰好存在：

# 1枚棋子

作为炮架。

例如：

```text
炮 —— 卒 —— 玩家
```

炮可以直接跳过卒：

吃掉玩家。

如果：

```text
炮 ————— 玩家
```

中间没有炮架：

不能吃。

如果：

```text
炮 —— 卒 —— 马 —— 玩家
```

中间有两个棋：

同样不能吃。

与玩家车相同。

不能穿棋。

如果敌车与玩家：

处于同一横线或者竖线，

并且中间：

# 没有任何棋子

敌车可以直接吃掉玩家。

## 中间0枚棋

# 车

## 中间1枚棋

危险来源：

# 炮

## 中间2枚以上

# 18. 基础回合制

游戏采用严格回合制。

只要玩家不操作：

# 棋盘不会发生任何变化。

一个完整回合为：

```text
玩家回合
↓
敌方回合
↓
增援结算
↓
进入下一玩家回合
```

---

# 19. 玩家回合完整顺序

每个玩家回合按照：

### ① 玩家可以选择使用1个道具

也可以不用。

↓

### ② 玩家移动一次车

可以：

- 普通移动
- 移动并吃子

↓

### ③ 处理击杀、连杀与计分

↓

### ④ 进入敌方回合

---

# 20. 每个玩家回合最多使用1个道具

玩家正常移动以前：

最多使用：

# 1个道具。

使用道具：

# 不消耗本回合正常移动。

因此：

```text
使用道具
↓
处理道具效果
↓
正常走车一次
```

---

# 21. 敌方永远只有1次行动

这是游戏核心固定规则。

无论隐藏难度多高：

# 每个敌方回合最多只有1枚敌棋行动。

永远不会增加到：

- 2枚
- 3枚
- 4枚

后期难度提升：

通过棋盘复杂度和AI质量实现。

---

# 22. 敌方行动可以是

敌方一次行动只能选择：

### A. 普通移动一枚棋

或者：

### B. 一枚棋直接吃掉玩家

---

# 23. 玩家允许主动进入危险位置

游戏不阻止玩家：

走入一个下一回合可能被吃的位置。

不会出现：

- 危险提示
- 二次确认
- 红色警告
- “是否确定移动”

只要移动：

符合车的正常移动规则，

就允许执行。

---

# 24. 敌方直接击杀优先级

敌方回合开始时：

首先寻找：

# 是否有棋能够立即吃掉玩家。

如果存在：

至少一枚可直接击杀玩家的棋，

敌方：

# 必定执行击杀。

不会为了逃跑或布局放弃可以直接杀死玩家的机会。

---

# 25. 多枚棋同时可以杀玩家

如果有多枚敌棋都能：

立即吃掉玩家，

任意选择其中一枚：

结果都为：

# 玩家死亡。

实现时推荐优先：

棋子价值更高者。

同价值时：

使用本局随机种子决定。

---

# 26. 敌方AI目标

如果当前不能立即击杀玩家：

AI会从所有合法行动中寻找：

# 综合收益最高的一步。

AI主要考虑：

1. 自身是否被玩家威胁
2. 是否能制造下一步杀招
3. 是否能减少玩家安全路线
4. 是否能保护重要棋子
5. 是否能与炮、车、马形成组合
6. 是否容易被玩家下一步吃掉

---

# 27. 什么叫“被玩家威胁”

如果当前敌棋：

位于玩家车的合法吃子位置，

即：

某一个方向上第一个遇到的敌棋，

则定义为：

# 被玩家车威胁。

由于车有四个方向：

玩家同一时间最多直接威胁：

# 4枚敌棋。

---

# 28. 多重威胁

如果玩家一次移动后同时威胁：

2枚棋：

# 双重威胁

3枚：

# 三重威胁

4枚：

# 四面楚歌

---

# 29. 多重威胁为什么重要

假设：

玩家同时威胁：

```text
炮
马
卒
```

敌方：

只有一次行动。

即使AI选择：

救走炮，

马和卒：

仍然无法同时逃跑。

玩家下一回合：

就可能继续击杀。

# 32. AI行动评分

除立即击杀以外：

可以按照以下基础评分计算。

### 成功脱离玩家直接威胁

普通棋子：

```text
+600
```

再加：

```text
棋子保护价值 × 3
```

将军保护不再从开局固定为最高优先级，而是跟随隐藏难度逐段成长：

| 隐藏难度 | 当前高于将的保护优先级 | 设计意图 |
|---|---|---|
| 1～5 | 马 | 前期允许马为了自身脱险而暂时放弃护将 |
| 6～8 | 炮 | 中期开始优先保炮，逐步收紧护将 |
| 9～12 | 车 | 中后期车的生存优先于将 |
| 13+ | 将 | 最后才把将军抬到全场最高优先级 |

实现时分别调整：

- 将军脱离直接威胁的加分；
- 其他棋子挡线护将的加分；
- 将军保持受威胁或被新暴露的扣分。

因此玩家在前中期会获得更明确的斩将窗口，后期才逐渐恢复“护将优先”的压力。

---

### 移动后形成下一回合直接杀玩家的机会

```text
+400
```

---

### 保护将

例如：

挡住玩家通往将的线路：

```text
+300
```

该评分适用于士或其他敌棋通过挡线解除将军的直接威胁。

---

### 建立有效炮架

```text
+180
```

---

### 封锁玩家移动空间

每减少一个：

玩家当前可安全移动位置：

```text
+30
```

---

### 移动后仍然处于玩家直接攻击范围

```text
-250
```

---

### 让高价值棋进入明显危险位置

额外扣除：

```text
棋子保护价值 × 2
```

# 33. AI难度成长方式

隐藏难度越高：

AI使用上述评分：

越准确。

实现方式不需要更换AI算法。

可以加入：

# 随机扰动值

低难度：

```text
-200 ～ +200
```

中等难度：

```text
-100 ～ +100
```

高难度：

```text
-40 ～ +40
```

极高难度：

```text
-10 ～ +10
```

最后：

选择：

```text
基础行动分 + 随机扰动
```

最高的行动。

这样：

前期AI偶尔会走出不完美的棋。

后期则越来越接近：

最佳选择。

# 52. 隐藏难度

# Difficulty Level

简称：

```text
D
```

玩家界面：

# 完全不显示D。

---

# 53. 隐藏难度计算

初始：

```text
D = 1
```

每成功完成：

# 4次普通增援

增加：

```text
D + 1
```

每击杀：

# 1个将

额外增加：

```text
D + 1
```

公式：

```text
D =
1
+ floor(累计成功普通增援次数 / 4)
+ 累计击杀将数量
```

---

# 54. 将存在期间仍会提升难度

将存在期间：

普通增援正常进行。

这些普通增援虽然：

不计入下一只将的触发计数，

但是：

# 仍然计入累计普通增援次数。

所以拖着将不杀：

游戏依然会继续变难。

# 166. 增援安全检查的最低要求

V1不需要：

搜索未来十几步是否必死。

只需要保证：

整批增援以后：

# 玩家下一回合至少存在一种合法移动，使下一敌方回合不存在立即击杀。

即：

# 一步生存校验。

这样已经足够：

排除绝大部分“系统直接刷死玩家”的恶性情况，

同时：

不会让生成算法成本过高。

# 167. AI可以将玩家逼入死局

安全保护：

只针对：

# 随机增援。

玩家在自己的走棋过程中：

如果一步一步把自己逼进：

无解状态，

AI：

# 可以正常将其杀死。

否则游戏就失去策略失败条件。

---

# 168. 设计原则：不要做绝对公平AI

AI目标是：

给玩家压力，

不是：

每一步都下理论最优棋。

否则：

单车对大量棋子的规则会很快失去容错。

因此：

即使最高隐藏难度，

也建议保留：

少量AI随机性。

---

# 169. 设计原则：难度主要来自棋盘

不增加：

敌方行动点。

不增加：

玩家血量伤害。

不增加：

棋子攻击力。

真正的难度增长来自：

- 棋子越来越多
- 单批增援越来越大
- 高威胁棋越来越多
- 增援越来越频繁
- AI越来越聪明
- 将出现越来越频繁

---

# 170. 设计原则：十字斩是压力释放阀

游戏允许：

棋盘积累到16～19枚棋。

因此必须存在：

强力清场能力。

道具十字斩（以及复活十字斩）就是：

# 核心压力释放机制。

---

# 171. 设计原则：将军必须值得冒险

斩将存在：

两层奖励：

### ① 高额300分

### ② 三选一道具

所以即使将：

处于危险位置，

玩家仍然有理由：

冒险去吃。

---

# 172. 设计原则：十字斩不能替代正常走棋

十字斩：

虽然强力，

但击杀普通棋：

只获得60%分数。

正常连杀：

最高可以达到：

×2分数。

因此高水平玩家：

依然会希望：

尽量通过正常走棋连续吃棋。

形成：

# 生存策略与高分策略的差异。

---

# 173. 设计原则：不允许静态拖时间

玩家：

不能跳过移动。

增援：

持续按照回合推进。

隐藏难度：

持续随着增援提高。

因此单纯：

绕着棋盘不杀敌

最终只会让：

敌棋越来越多。

# 176. 最终一句话玩法

> **玩家只控制一枚车，在持续落下的象棋敌子中，通过走位、吃子和多重威胁操纵敌方每回合唯一的一次行动；随着隐藏难度提升，单批增援由1枚逐渐增加到最多4枚，棋盘压力持续累积；每隔若干次增援，士・将・士降临，玩家冒险斩将获得三选一道具，然后继续迎接下一轮不断升级的无尽棋局，直到最终被敌棋吃掉。**

# 《桌面大清理》首版实现基线

- 单个正式挑战关，每次开局随机生成布局；重新挑战会重新摆桌。
- 144 件大尺寸物品、二十四个扩展遮挡层、七格槽位、180 秒；每层包含两组完整三件组，幸运徽章仍为三枚并固定在最深层。第三件同类必须先完整飞入槽位，随后三件在槽内汇聚并由独立烟雾序列帧遮盖消失，烟雾开始后才提交槽位移除、后续物品前移、得分和通关判定；清空桌面并收齐三枚幸运徽章获胜。
- 物品运动采用轻量 2D 物理解算：模型保存线速度、角速度和抬升量，颠锅冲量优先作用于露出物件，同层物件做代理碰撞，边界提供阻尼反弹；初始化和动态边界按放大物品旋转后的包围盒及桌板内边距收紧，抬升量只用于伪 3D 显示深度和轻微抬升缩放，不播放翻开脉冲，也不把 144 件物品全部挂接为动态刚体。
- 颠锅只在微信真机使用平台加速度计；浏览器预览不模拟设备颠锅，手指移动仍按最终抬起位置更新并拾取候选；暂停、规则、广告和退出期间不推进运动。
- 全屏胡桃木背景不得包含奶油色桌板；桌板使用独立 1:1 正方形正式纹理，与物品堆共同位于 `PlayAreaRoot`。正常屏幕下中部玩法区边长等于可见宽度，若顶部 HUD 与底部控件之间放不下，则桌板、物品堆和局部特效整体等比缩小并水平居中。
- 物品以不规则、非对称的散乱方式分布在独立桌板约 80%–85% 的宽度范围内，底层被上层连续覆盖，不使用环形锚点或规则花瓣形骨架。每种物品维护一个与最终 SpriteFrame 对齐的归一化外轮廓多边形；手指按下或移动时按显示层级从上到下查询，并把触点逆变换到物品局部坐标后执行点在多边形内判断，同时给当前候选物品加轮廓提示；抬起时按最终触点重新查询并执行拾取。任何真实露出且点中主体的物品都能进入槽位，透明区域、投影和完全被覆盖的部分不得截获点击。
- 运动层的 `free` 只作为冲量权重、道具优先级和露出提示，不能作为全局点选开关；真正的拾取资格仍由当前节点显示顺序与物品自身外轮廓决定，确保“能看见就能拾取”。
- 顶部标题徽标、帮助/暂停按钮和倒计时底板，以及底部七格槽体、三张道具卡、道具图标、问号和次数徽章，全部使用由已确认效果图派生的 `game-catch` 正式透明纹理，不以扁平程序图形替代，也不直接切割整张效果图作为运行时界面。
- 三个道具每局各免费一次：退回最近三件、自动凑齐一组、重排剩余桌面。
- 免费次数后整局最多一次道具广告；收纳槽满时的失败广告清出 3 格，超时失败广告才加时 60 秒。每类只发起一次，只有完整播放发奖。
- 首次规则卡加 HUD 帮助入口，不制作教学关。
- 本地记录包括局数、胜场、最高分、最快通关、最后通关日期和规则已读版本，不保存中途进度。
- 首轮图片直接生成并接入；音频只交付原创外部生成提示词，游戏在音频入库前保持 `development`。

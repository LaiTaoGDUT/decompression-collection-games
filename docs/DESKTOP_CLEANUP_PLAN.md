# 《桌面大清理》首版实现基线

- 单个正式挑战关，每日按本地日期固定布局；同日重开不换桌。
- 72 件大尺寸物品、十二个紧凑遮挡层、七格槽位、180 秒；每层包含两组完整三件组。第三件同类必须先完整飞入槽位，随后三件在槽内汇聚并由独立烟雾序列帧遮盖消失，烟雾开始后才提交槽位移除、后续物品前移、得分和通关判定；清空桌面并收齐三枚幸运徽章获胜。
- 全屏胡桃木背景不得包含奶油色桌板；桌板使用独立 1:1 正方形正式纹理，与物品堆共同位于 `PlayAreaRoot`。正常屏幕下中部玩法区边长等于可见宽度，若顶部 HUD 与底部控件之间放不下，则桌板、物品堆和局部特效整体等比缩小并水平居中。
- 物品只占独立桌板中部约 55%–60% 的宽度，底层被上层连续覆盖。每个最终 SpriteFrame 必须产出逐像素 Alpha 命中掩码，输入按显示层级从上到下查询实体像素；任何真实露出且点中不透明主体的物品都能进入槽位，透明像素、投影和完全被覆盖的部分不得截获点击。
- 拖动堆放区域时，当前最高非空层及其下方三层逐帧跟随手指，位移权重固定为 `1 / 0.58 / 0.30 / 0.14`，更深层不动；抬手后缓动回稳，不得瞬移或一次性重排，也不得显示“上层物件拨开了一点”或同义提示。
- 顶部标题徽标、帮助/暂停按钮和倒计时底板，以及底部七格槽体、三张道具卡、道具图标、问号和次数徽章，全部使用由已确认效果图派生的 `game-catch` 正式透明纹理，不以扁平程序图形替代，也不直接切割整张效果图作为运行时界面。
- 三个道具每局各免费一次：退回最近三件、自动凑齐一组、重排剩余桌面。
- 免费次数后整局最多一次道具广告；失败后另有一次加时 60 秒广告。每类只发起一次，只有完整播放发奖。
- 首次规则卡加 HUD 帮助入口，不制作教学关。
- 本地记录包括局数、胜场、最高分、最快通关、最后通关日期和规则已读版本，不保存中途进度。
- 首轮图片直接生成并接入；音频只交付原创外部生成提示词，游戏在音频入库前保持 `development`。

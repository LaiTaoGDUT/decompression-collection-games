# 《桌面大清理》视觉规范 V1.0

## 1. 视觉所有权

- 主题名：**软陶微缩工作台**。
- 关键词：圆润、温暖、可触摸、轻微凌乱、整理后的清爽感。
- 所有游戏内图片归 `game-catch` Bundle；大厅图标与封面是独立生成的大厅展示副本。
- 禁止复用大厅、合成大胖橘、霓虹 2048、滑块拼图、棋类或无尽剑域的正式色板、按钮、图标、背景、特效或音频。
- 禁止出现鹅、锅、参考游戏标题/标志、可识别品牌包装、真实商标、参考游戏界面布局或相同物件组合。

## 2. 色彩与材质

| 语义 | 色值 | 用途 |
|---|---:|---|
| 墨蓝 | `#273045` | 正文、轮廓、深色槽位 |
| 暖奶油 | `#F8E8C7` | 工作垫、弹窗、留白 |
| 珊瑚 | `#EB7764` | 主行动、失败警示、铅笔/键帽 |
| 青绿 | `#56B1A6` | 帮助、继续、便签/U 盘 |
| 芥末黄 | `#E8B445` | 幸运徽章、纪录、面板描边 |
| 淡紫 | `#9B7EB0` | 重排道具、解压球 |

物件表现为哑光软陶与少量半透明树脂，边缘厚实圆润，无锐利金属高光。统一采用俯视 3/4 角、左上方大面积柔光、右下短软阴影。缩小到约 80–120 设计像素时仍须依靠轮廓与主色辨认。

## 3. 构图与 UI

- 设计基准 750×1334，Canvas 使用 Fit Width；横向占满可见宽度，纵向避让微信胶囊、顶部安全区和底部安全区。
- 全屏背景与玩法桌板必须拆分。背景只包含深胡桃色软陶工作台及边缘环境装饰，按 cover 等比铺满，禁止烘焙奶油色桌板、物件堆或 UI；奶油色桌板使用独立 1:1 正方形透明纹理，并与物件堆共同挂在 `PlayAreaRoot` 下，以同一位置和同一比例缩放。
- 顶部为确认效果图派生的正式纹理：物件组合徽标、无文字帮助按钮、无文字暂停按钮和带双层边沿、铆钉及软陶阴影的倒计时底板。倒计时数字可以动态渲染，但字形、颜色和间距必须与确认效果图一致；常驻 HUD 不展示得分或清理进度，禁止再以扁平 `Graphics` 近似正式皮肤。
- 中部玩法区始终为 1:1 正方形，正常屏幕下边长等于可见宽度并横向铺满；其垂直位置取顶部 HUD 底边与底部收纳槽顶边之间的居中位置。若上下安全边界之间无法容纳完整正方形，则对整个 `PlayAreaRoot`（桌板、物件堆和局部特效）等比缩小并水平居中，禁止裁切、拉伸桌板或让物件与桌板分别适配。72 件大尺寸物品集中在桌板中部约 55%–60% 宽度的单一椭圆区域内，组成十二个紧密交错的遮挡层；每层 6 件、相邻层大面积压叠，底层通常只露出边角，禁止铺满桌板、规则网格、横纵队列或多个独立小堆。
- 底部从上到下依次为七格收纳槽和三个图标化道具卡。七格槽体、三张软陶卡片底板、三个道具图标、右上问号徽章和右下次数徽章都必须使用由确认效果图派生并经透明边缘整理的本游戏正式纹理；不得以纯色圆角矩形、程序描边或通用矢量图标代替。默认界面不常驻教学提示文字，只有受阻、道具结果等必要反馈可使用短时浮层。
- 每张道具卡右上角有独立的无文字问号图标，点击后弹出当前道具的名称、效果、使用条件和广告补充规则；点击问号不得误触道具。
- 矮屏优先缩小中部正方形玩法区，仍不足时再等比缩小完整 HUD/底部控件组合；不得裁切槽位、道具或 HUD。高屏保留自然桌面留白。
- 规则、暂停、失败和结算面板采用奶油色厚软陶卡片、芥末黄描边及深色遮罩；按钮为高饱和软陶胶囊，不使用其他游戏的弹窗皮肤。

### 3.1 图标与物件边界

- 顶部帮助、暂停、标题徽标和三个道具符号全部使用本游戏正式透明纹理，不用 `Label`、Unicode 字符、字体字形或运行时临摹的扁平矢量图标冒充。
- 物品 SpriteFrame 必须按每格 Alpha 有效范围裁边，显示尺寸保持裁剪后图片原始宽高比；不再为文具追加统一灰色圆角底板或灰色描边。过长、过细、带大面积透明三角区或不规则细小突出部的文具必须重制为短粗、圆润、主体明确的版本后才能进入候选构建。
- 点击不得使用裁边矩形、椭圆、圆角矩形或按类别手写的近似形状。每个物品必须由其最终 SpriteFrame 的逐像素 Alpha 生成命中掩码；触点先逆变换到节点局部 UV，再以统一 Alpha 阈值查询掩码，并按实际显示顺序从上到下解析。点到上层实体像素就收上层，点到下层真实露出的实体像素就收下层，透明像素、投影和完全被覆盖的部分不得截获输入。

## 5. 动效与反馈

- 点选：物件先在约 70ms 内轻抬，再沿带弧度的路径在约 260ms 内飞向其实际槽位，抵达后槽位轻微回弹；不允许原地缩小淡出冒充入槽动画。
- 三消：第三件物品必须先完整飞入并占据实际槽位，三件同类在槽内至少呈现一个稳定帧；随后三件以各自当前位置向三者中心汇聚，汇聚完成后播放透明烟雾序列帧并在烟雾遮盖下消失，烟雾开始后才提交槽位移除、后续物品前移、得分与通关判定。禁止第三件落槽前或落槽同帧直接删除三件。
- 被压物件：水平短促摇摆，不改变层级。
- 滑动拨散：手指在正方形玩法区移动时，当前最高非空层及其下方三层必须逐帧跟随触点位移，位移权重依次固定为 `1 / 0.58 / 0.30 / 0.14`；第五层及更深层保持不动。所有参与层从触摸开始位置计算偏移并受紧凑堆边界约束，抬手后短时缓动回稳，禁止在抬手时瞬移或一次性重排。该手势不显示“上层物件拨开了一点”或同义提示。
- 剩余 30 秒：倒计时转珊瑚色；禁止全屏频闪。
- 胜利：幸运徽章与芥末色短粒子庆祝；失败仅使用轻微面板震动与色彩提示。

## 6. 独立声音方向

- 声音主题：**桌面材料小乐队**。以软陶轻弹、木桌指敲、软木与树脂短触感为核心，整体干燥、圆润、近距离，强化“拿起—归位—桌面变清爽”的满足感。
- 游戏音乐以低密度木质敲击、柔和短音槌和极轻的软陶节拍构成，不使用抢眼主旋律；必须给高频点选、三消与警告反馈留出空间。
- 高频操作反馈保持短促，准备 3 个拾取微变体，禁止长混响、尖锐高频或夸张低频；失败不使用惊吓音，胜利也不采用大型管弦庆典。
- 禁止复用或仿制大厅纸张/画廊声音、合成大胖橘的水果与猫叫、2048 的霓虹电子脉冲，以及其他游戏的正式音频、旋律和文件。
- 首个开发版本保持静音，只接入反馈事件名；正式音频必须按 `docs/DESKTOP_CLEANUP_AUDIO_PROMPTS.md` 手工生成、记录来源、验收并导入后，才允许将 Manifest 可见性从 `development` 提升。

# 《棋逢对手·无尽挑战》
# 音乐 / 音效 / 特效 / 图片素材规划 V1.0

## 1. 文档目标

本方案用于配套《棋逢对手·无尽挑战》核心玩法。

主要定义：

- 背景音乐 BGM
- 游戏音效 SFX
- 棋盘视觉特效 VFX
- UI动效
- 图片及图标素材
- 各资源具体触发时机
- 资源复用规则
- 资源命名建议
- V1制作优先级

整体目标不是做成传统战争象棋，而是营造：

> **轻松进入 → 安静思考 → 压力逐渐增加 → 将军登场 → 紧张斩将 → 十字清场爆发 → 短暂舒缓 → 再次进入棋局**

的循环体验。

整体美术和声音建议：

**东方、清爽、轻策略、有一点古韵，但不过度厚重。**

---

# 2. 整体视听基调

游戏虽然使用中国象棋元素，但不建议采用：

- 沉重战争音乐
- 大量锣鼓
- 激烈武侠战斗BGM
- 过度金光特效
- 传统棋牌室风格

更适合：

# 「东方轻策略」

关键词：

- 木质
- 竹
- 玉
- 墨
- 金属轻鸣
- 古琴
- 箫
- 木鱼/木击
- 轻打击乐
- 环境氛围

玩家大量时间都在：

**思考下一步。**

所以声音不能过度吵闹。

---

# 3. 音乐系统总体结构

V1建议准备：

# 2首主BGM + 4个音乐短句/提示音

而不是做大量独立曲目。

---

# 5. BGM 01：普通棋局音乐

资源名：

`bgm_game_normal`

进入正式棋局后播放。

这是玩家绝大部分时间听到的音乐。

整体：

# 安静、克制、有节奏感。

建议：

- 古琴拨弦
- 轻木击
- 极弱鼓点
- 稀疏箫声
- 环境底音

BPM建议：

**80～95**

重点：

玩家停下来思考时：

音乐不能制造时间压力。

因此不要：

- 快节奏鼓点
- 明显倒计时感
- 强烈循环节拍

---

# 6. BGM 02：高压棋局层

资源名：

`bgm_game_pressure`

不是完全换一首音乐。

更推荐：

# 在普通BGM基础上增加一层音乐。

例如：

Normal：

```text
古琴
+
环境氛围
```

Pressure：

```text
古琴
+
环境氛围
+
低频鼓点
+
轻弦乐持续音
```

这样切换时：

不会突然换歌。

---

# 7. 高压音乐什么时候触发？

玩家不看到隐藏难度。

但是系统可以根据棋盘情况动态进入高压音乐。

满足任意一个条件：

### 条件A

场上敌棋：

**≥16枚**

### 条件B

将存在于棋盘

### 条件C

下一批增援：

**≥3枚**

并且：

距离增援：

**≤1回合**

触发：

`music_pressure_on`

退出条件：

将不存在，

并且：

敌棋：

**≤15枚**

持续至少：

2个完整回合。

防止音乐：

来回频繁切换。

---

# 8. 将军登场音乐短句

资源：

`sfx_music_general_arrive`

属于：

# Music Stinger

不是完整BGM。

长度：

**1.5～2.5秒**

将军：

```text
士 将 士
```

正式落下瞬间播放。

风格：

- 一声低沉鼓
- 短促古琴扫弦
- 金属/锣的低频尾音

效果：

让玩家明确感受到：

# 「重要事件发生了。」

同时：

普通BGM继续存在。

Stinger播放时：

BGM短暂降低音量。

---

# 9. 击杀将军音乐短句

资源：

`sfx_music_general_kill`

触发：

# 将被击杀瞬间。

长度：

约：

**1～1.5秒。**

感觉：

- 清脆
- 胜利感
- 不要太宏大

例如：

快速古琴上行音 +

短促金属清鸣。

随后出现：

三选一道具。

---

# 10. 十字斩音乐爆点

资源：

`sfx_music_cross_slash`

长度：

**0.8～1.2秒。**

不是普通刀剑音。

需要明显区别于：

普通吃棋。

感觉：

> 蓄力 → 一瞬间释放 → 尾音扩散

可以使用：

- 低频冲击
- 风切
- 金属轻鸣

配合十字斩视觉特效。

---

# 11. 死亡音乐短句

资源：

`sfx_music_game_over`

触发：

玩家车被吃掉。

时长：

约：

**1.5秒。**

不需要悲壮。

建议：

古琴低音：

快速下落。

然后：

BGM降低或暂停。

弹出：

死亡 / 复活界面。

---

# 13. 基础棋子音效

所有棋子移动：

都需要声音。

但：

玩家与敌方必须能通过声音区分。

---

# 14. 玩家车移动

资源：

`sfx_player_move`

触发：

玩家车完成正常移动。

声音：

# 清晰的木棋落在棋盘上的声音。

类似：

「哒」

不要太重。

---

# 15. 玩家吃子

资源：

`sfx_player_capture`

触发：

玩家通过正常移动吃掉敌棋。

声音：

由：

```text
移动落子声
+
较清脆的碰撞声
```

组合。

感觉：

比普通移动：

更扎实、更爽。

---

# 16. 连杀声音

Combo：

不需要每次播放完全不同的语音。

推荐：

普通吃子音效基础上：

随着Combo提高：

增加一个音高层。

例如：

Combo 1：

普通吃子

Combo 2：

加入一个高音

Combo 3：

再高一点

Combo 4：

明显清脆

Combo 5+：

保持最高档

资源可以：

程序动态Pitch。

或者准备：

`sfx_combo_2`

`sfx_combo_3`

`sfx_combo_4`

`sfx_combo_max`

---

# 17. 敌方普通移动

资源：

`sfx_enemy_move`

比玩家车：

声音稍轻。

目的：

让玩家不用盯屏幕也知道：

# 「敌人动了一步。」

---

# 18. 不同敌棋是否需要不同移动声？

V1：

# 不需要。

卒、士、象、马、炮、车：

可以共享：

`sfx_enemy_move`

否则音频数量会快速膨胀。

但：

敌方车可以额外稍微增加：

低频木声。

作为后续优化。

---

# 19. 敌棋吃掉玩家

资源：

`sfx_player_killed`

触发：

敌棋落到玩家车的位置。

组成：

```text
重落子
+
木棋碰撞
+
短促低频Impact
```

随后：

玩家棋子消失/破碎。

这是全游戏最需要：

明确反馈

的声音之一。

---

# 20. 增援倒计时声音

平时：

# 不播放倒计时声音。

避免玩家每回合都听到：

滴、滴、滴。

只有：

下一回合即将增援时：

播放：

`sfx_reinforcement_ready`

声音非常轻：

类似木牌翻动 / 小铃。

提醒玩家：

# 下一轮增援马上到。

---

# 21. 普通增援落地

资源：

`sfx_reinforcement_drop`

当1～4枚棋：

正式落入棋盘。

推荐：

每枚棋使用同一个落子声音，

但间隔：

**40～80ms**

形成：

```text
哒
哒
哒
哒
```

而不是四枚棋：

完全同时一个巨响。

---

# 22. 多枚增援声音力度

增援1枚：

普通声音。

2枚：

连续两次。

3枚：

第三下稍重。

4枚：

最后一下增加一点低频。

使玩家通过听觉就能感觉：

> “这一批有点多。”

---

# 23. 增援待命

增援因为：

场上 >24枚

而无法进入时：

不需要持续播放声音。

第一次进入：

「等待入场」

状态时：

播放一次：

`sfx_reinforcement_wait`

类似：

轻微卡住/木牌扣住声音。

---

# 24. 将军待降

特殊增援：

士・将・士

进入待降时：

播放：

`sfx_general_wait`

声音比普通增援：

稍明显。

但不能重复播放。

---

# 25. 将军落地声音

士、将、士：

依次快速落下：

```text
士
↓
将
↓
士
```

视觉上可以：

三枚几乎同时落地。

声音：

两侧士：

普通落子声。

中央将：

# 更重的一声。

最后接：

`general_arrive stinger`

---

# 26. 道具获得

击杀将后：

三选一道具面板出现。

播放：

`sfx_reward_open`

建议：

木匣打开 +

轻金属铃声。

---

# 27. 道具选择

点击选择道具：

`sfx_item_select`

短促清脆：

「叮」。

然后卡片飞入：

道具栏。

---

# 28. 道具栏点击

点击任意可用道具：

`sfx_ui_item_click`

非常轻。

不要与：

真正释放音效

混淆。

---

# 29. 十字斩道具

开始释放：

`sfx_cross_charge`

约：

0.2～0.3秒。

随后：

`sfx_cross_slash`

强冲击音。

如果击杀多枚棋：

不要每枚棋都完整播放：

普通击杀音。

否则会变成：

“哒哒哒哒哒哒”。

统一使用：

十字斩Impact +

一个轻量：

`sfx_multi_capture`

即可。

---

# 30. 定身符

使用：

`sfx_item_freeze`

声音：

- 清脆符咒音
- 轻微冰/玉质声

不要真的做成：

冰系魔法。

视觉仍偏：

东方符咒/封印。

---

# 31. 缓兵符

资源：

`sfx_item_delay`

声音建议：

木制机关：

「咔」

然后：

增援倒计时数字：

向后翻动。

---

# 32. 驱逐令

资源：

`sfx_item_banish`

感觉：

快速吸走 +

纸符扫过。

目标棋：

不是爆炸死亡。

而是：

被“卷走”。

用于强化：

# 这不算击杀。

---

# 33. 移形符

资源：

`sfx_item_teleport`

使用：

轻风 +

空间闪移。

不要：

科幻传送音。

# 34. 复活音效

广告成功后：

进入复活。

第一段：

`sfx_revive`

声音：

低到高的恢复音。

随后：

立即自动十字斩：

继续播放：

`sfx_cross_slash`

形成：

# 复活 → 爆发清场

的强反馈。

# 37. 特效设计原则

特效首先服务于：

# 棋盘信息读取。

不能为了华丽：

挡住棋子。

尤其：

棋盘可能出现20～28枚敌棋。

因此所有VFX：

需要：

- 时间短
- 透明度适中
- 不遮挡棋子文字
- 不造成错误危险提示

---

# 38. 玩家选中效果

玩家点击自己的车：

车棋子：

轻微：

# 上浮 + 外圈光晕。

同时展示：

合法移动格。

注意：

这些格子只表示：

# 「车可以走到」

不是：

安全格。

---

# 39. 合法移动格特效

推荐：

格子中心：

小圆点。

可以吃子的敌棋：

棋子下面：

显示：

轻微目标圈。

绝对不要使用：

红色危险提示。

---

# 40. 玩家移动特效

玩家车移动：

不建议逐格跳动。

使用：

# 快速平移。

时间：

**120～180ms**

移动路线：

留下极淡的：

墨色/风痕。

很快消失。

---

# 41. 普通吃子特效

玩家车撞到敌棋：

目标棋：

### ① 轻微放大

### ② 向后震动

### ③ 碎成2～4块墨/木屑

### ④ 淡出

总时长：

**200～300ms**

不要做：

爆炸。

---

# 42. 敌方移动特效

敌棋：

快速滑动到目标位置。

时间：

约：

**150ms**

不需要路线轨迹。

因为玩家需要快速：

看清最终棋局。

---

# 43. 敌方吃玩家特效

敌棋移动到玩家位置。

玩家车：

### 第一阶段

受到冲击：

快速震动。

### 第二阶段

车棋子：

裂开。

### 第三阶段

碎片 / 墨迹散开。

### 第四阶段

屏幕：

轻微暗下来。

随后：

死亡界面出现。

总时长建议：

**500～700ms**

---

# 44. 不建议棋盘整体震屏

普通吃子：

不震屏。

玩家死亡：

可以极轻：

# 2～3px震动。

十字斩：

可以：

轻微冲击一次。

否则：

回合频繁操作会产生视觉疲劳。

---

# 45. 普通增援预告特效

因为：

不在棋盘提前显示落点，

所以所有预告特效：

集中在：

# 增援面板。

例如：

剩余：

2回合

面板正常。

剩余：

1回合

面板边缘：

缓慢呼吸一次。

不要：

一直闪烁。

---

# 46. 普通增援落地特效

真正确定位置以后：

对应空格：

先出现：

# 极短的落点波纹。

时间：

约：

150ms。

然后棋子：

从上方约20～30px：

快速落下。

落地：

小型尘埃 / 墨圈扩散。

---

# 47. 多枚增援落地

1～4枚棋：

建议：

# 依次间隔50ms落下。

例如4枚：

```text
0ms
50ms
100ms
150ms
```

总时间仍然很短。

既能看清：

有几枚新棋。

又不会拖节奏。

---

# 48. 将军落地特效

特殊增援：

```text
士 将 士
```

需要明显区别。

流程：

### ① 棋盘轻微压暗

约：

150ms。

### ② 三个目标位置出现

非常短暂的：

墨色圆阵。

注意：

这是：

# 已经确定位置后的入场动画

不是提前预告。

### ③ 两个士落下

### ④ 将重落中央

### ⑤ 中央出现一圈金/墨冲击波

### ⑥ 显示：

# 「将军！」

文字约：

0.8秒。

然后恢复正常棋盘。

---

# 49. 将棋子常驻特效

将存在时：

不需要一直发光。

只需要：

棋子底部：

非常轻的特殊纹章。

让它：

比普通棋更有辨识度。

---

# 50. 击杀将特效

将被击杀：

不要直接普通碎裂。

建议：

### ① 将棋子短暂定格

约：

100ms。

### ② 中央出现裂纹

### ③ 金色/墨色碎光散开

### ④ 显示：

# 「斩将」

### ⑤ 三选一道具出现

让玩家感受到：

这是一个阶段性成果。

---

# 51. 十字斩核心特效

这是整个游戏：

# 最重要的视觉爽点。

必须单独重点制作。

流程建议：

### 0ms

玩家车：

快速缩小一点。

形成：

蓄力感。

### 100ms

车：

闪一下。

### 150ms

横向：

一道能量/墨迹冲击线。

纵向：

同时爆开。

形成：

# 十字

### 200～350ms

十字线扫过整张棋盘。

### 250～450ms

所有被击中的敌棋：

依次爆成：

墨片 / 木屑 / 光粒。

### 500ms

棋盘恢复。

整个过程：

控制在：

# 0.5～0.7秒。

---

# 52. 十字斩视觉风格

不推荐：

科幻激光。

推荐：

# 水墨刀光 / 金色棋气

例如：

核心：

淡金色。

边缘：

墨色飞散。

视觉上：

既有杀伤力，

又保持：

东方棋局主题。

所有目标：

一道小符纸飞过。

棋盘：

完全不需要特效。

# 57. 驱逐令特效

快速缩小。

视觉上应该明显不同于：

出现。

整个过程：

250ms。

# 59. 复活特效

广告完成：

死亡界面关闭。

棋盘恢复：

致死行动之前的状态。

然后：

### ① 玩家车位置出现光点

### ② 车重新显现

### ③ 一圈能量向外扩散

### ④ 立即释放十字斩

# 101. 最终资源制作原则

整个项目资源制作应该遵循：

> **棋盘永远优先保证清晰，声音永远优先表达事件重要性，特效永远优先强化玩家操作反馈。**

普通操作：

轻。

增援：

明确。

将军：

隆重。

斩将：

爽。

十字斩：

全局最强反馈。

死亡：

清楚且干净。

不要让：

每一个小操作都非常华丽。

只有这样，

真正出现：

# 「士・将・士」

和：

# 「十字斩」

时，

玩家才会明显感觉：

**“大事件来了。”**

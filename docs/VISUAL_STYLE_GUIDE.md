## 1. 冻结原则：每个体验单独设计

大厅、合成大西瓜以及未来每个小游戏都是独立视觉单元。它们不共享品牌色板、字体气质、圆角语言、卡片造型、图标风格、插画风格、动效节奏或音效气质。

只共享以下功能质量基线：

- 设计基准 750 × 1334、竖屏安全区、微信右上角胶囊避让和常见长短屏适配。
- 关键触摸区域不小于 88 × 88 设计单位。
- 正文对比度目标不低于 4.5:1，大号文字和关键图形不低于 3:1。
- 正常、按下、等待、禁用、失败和恢复状态语义完整。
- 异步动作单任务锁、广告失败降级、前后台安全暂停和无死路返回。
- 低档设备可降级非必要粒子、阴影和复杂过渡，但不删除操作反馈。
- 所有素材来源、许可、Bundle、修改和真机证据进入统一台账。

这些是可用性与工程约束，不是视觉统一要求。

### 平台原生 UI 避让（所有现有与未来游戏强制执行）

- 微信右上角胶囊属于不可覆盖的原生交互区域，标题、暂停、设置、计分卡等不得进入其矩形范围。
- 游戏不得按截图或单一机型写死胶囊坐标；必须读取 `Platform.getLayoutInfo()`，并使用共享的 `calculateTopRightControlPosition()` 布局右上角常驻操作。
- 胶囊下方默认保留至少 10 设计单位间距；没有胶囊信息的 Web/开发环境保持各主题原有顶部构图。
- 主题可以自行决定按钮皮肤、尺寸和文案，但不能绕过平台布局约束；新增游戏的设计评审与真机验收必须包含胶囊不遮挡检查。

## 2. 视觉所有权

| 界面/资源 | 视觉所有者 | 规则 |
| --- | --- | --- |
| 冷启动、品牌区、大厅、设置 | 大厅主题 | 使用大厅独立色板、字体、图标、控件和动效 |
| 大厅游戏卡与敬请期待卡 | 大厅主题 | 外框和列表属于大厅；游戏封面作为独立世界的预览窗口 |
| 游戏加载失败（尚未进入游戏） | 大厅主题 | 游戏资源不可用时仍能稳定返回大厅 |
| 合成大西瓜 HUD、容器、暂停、失败、续玩、结算 | 合成大西瓜主题 | 不复用大厅视觉令牌或大厅 Prefab 外观 |
| 游戏内广告等待壳 | 当前游戏主题 | 平台广告画面除外；业务等待和结果反馈属于游戏 |
| 返回大厅后的页面 | 大厅主题 | 游戏主题资源在退出后释放 |
| 未来小游戏全部界面 | 对应小游戏主题 | 每款单独建立规范和素材台账条目 |

`assets/shared` 只保留行为接口、状态逻辑、无品牌技术底座和开发回退，不作为候选版本的统一视觉皮肤。共享 `PausePresenter`、`ResultPresenter` 等行为接口可以保留，但正式呈现必须允许由当前视觉所有者提供主题化或游戏自有视图。

## 3. Bundle 隔离

```text
assets/lobby/
  ├─ scenes/、scripts/
  └─ visual/                 # 大厅独立视觉、图标、动效、音频

assets/games/watermelon/
  ├─ scenes/、scripts/
  └─ visual/                 # 合成大西瓜独立完整视觉与游戏内 UI

assets/shared/
  ├─ components/             # 行为协议与无品牌技术组件
  └─ fallback/               # 仅启动容错/开发回退，候选构建不作为正式皮肤
```

- 大厅不得加载 `game-watermelon` 的游戏内视觉资源。
- 合成大西瓜不得引用大厅色板、图标、按钮 Sprite 或大厅 Prefab。
- 游戏封面为了由大厅安全加载，文件位于 `lobby` Bundle，但必须由对应小游戏的独立方向派生并在台账标记“大厅展示副本”。
- 主题切换不得修改 `GameManifest`、Session、存档和广告结果语义。

## 4. 大厅视觉方向候选

### L1：柔光收藏馆（推荐）

像安静的现代收藏展柜：暖灰或象牙白空间、细致网格、克制阴影、游戏封面像独立展品。大厅本身保持中性，让每个小游戏封面拥有自己的色彩。

- 气质：清爽、成熟、安静、可扩展。
- 候选色：象牙白、暖灰、石墨黑，少量香槟金或鼠尾草绿。
- 字体气质：现代无衬线、明确层级、编辑设计感。
- 卡片：简洁展签/收藏盒，不使用水果或具体游戏装饰。
- 敬请期待卡：半透明空展位、柔和虚线或空展签。
- 优点：最能容纳未来完全不同的游戏视觉，不会抢封面。
- 成本：低到中；主要依赖布局、光影和少量环境插画。

### L2：夜航游戏站

像深夜仍亮着灯的小型游戏驿站：深蓝黑背景、暖色窗口、低亮霓虹导视，每张游戏卡像一个通往不同世界的入口。

- 气质：沉浸、都市、夜间陪伴。
- 候选色：靛蓝、墨黑、暖黄、少量电光青。
- 字体气质：几何无衬线、导视系统感。
- 卡片：发光窗口，但发光强度统一，不设主推。
- 敬请期待卡：未点亮的下一站窗口。
- 优点：独立性强，封面在深背景上突出。
- 成本：中；需控制发光、对比和低档性能。

### L3：云端游乐台

大厅像漂浮在天空中的轻型游戏平台：大面积天光、云层、柔和蓝紫渐变，卡片像悬浮岛或票券。

- 气质：轻盈、开放、治愈。
- 候选色：天蓝、云白、淡紫、日落橙。
- 字体气质：圆润无衬线，但保持成熟比例。
- 敬请期待卡：远处尚未靠站的小岛。
- 优点：减压感直接，适合轻量内容合集。
- 成本：中；背景适配和悬浮层次需细致处理。

### L4：减压手帐

大厅像一本用户自己的小游戏收藏手帐：纸张、胶带、页签和轻量手绘标记，每张卡是独立贴入的内容页。

- 气质：个人、温暖、可收藏。
- 候选色：米纸色、墨色、低饱和拼贴色。
- 字体气质：正文清晰无衬线，标题可有少量手写感。
- 敬请期待卡：留白页或未贴内容的相框。
- 优点：能解释不同游戏封面风格共存。
- 成本：中；素材数量和纹理一致性要求较高。

### L5：微缩玩具柜

大厅是一组立体微缩展柜，每个游戏拥有独立格子，卡片像盒装玩具陈列。

- 气质：收藏、触感、精致、趣味。
- 候选色：中性柜体色，让各游戏盒面决定色彩。
- 字体气质：包装标签感。
- 敬请期待卡：空置透明展示格。
- 优点：视觉记忆强，天然支持“更多游戏”。
- 成本：高；需要稳定的透视、光照和多比例适配。

## 5. 合成大西瓜视觉方向候选

### W1：夏日果摊纸雕（推荐）

像夏日下午的原创水果摊：明快水果、纸雕切层、手写价签意象和轻量遮阳棚元素。只存在于游戏内与该游戏封面，不延伸到大厅外框。

- 气质：多汁、轻松、热闹但不杂乱。
- 水果：清晰纸雕轮廓、细微表情、统一侧光。
- UI：果摊价签、木箱/纸盒容器的抽象化表达。
- 动效：果汁飞溅、纸屑、弹性挤压。
- 成本：中；2D 资源易控制，11 级辨识度高。

### W2：清透果冻实验室

水果像半透明果冻球，场景是干净的实验舱或透明容器，合成反馈强调折射、气泡和弹性。

- 气质：清凉、现代、满足感强。
- UI：实验标签、刻度和玻璃容器。
- 动效：气泡、凝胶波纹、柔性形变。
- 成本：中到高；透明与叠层对低档设备要求更高。

### W3：复古水果市场

采用原创复古印刷、丝网套色和市场招牌感，水果为粗颗粒平涂，分数与结算像价格牌或收据。

- 气质：怀旧、鲜明、有个性。
- UI：纸牌、印章、收据、木箱图形。
- 动效：套色错位、印章落下、纸带飘动。
- 成本：中；需谨慎控制中文字体和纹理可读性。

### W4：蜡笔果园绘本

水果、容器和背景均使用原创蜡笔/粉彩笔触，碰撞留下短暂涂抹和星点。

- 气质：柔软、亲切、手作。
- UI：绘本页角、手绘线条、色块按钮。
- 动效：手绘逐帧抖动、蜡笔粉末。
- 成本：中；需避免低龄化并保持碰撞边界准确。

### W5：软陶水果玩具箱

水果呈软陶或搪胶玩具质感，容器像桌面玩具盒，光影柔和、体积感强。

- 气质：触感、收藏、可爱但不幼稚。
- UI：压印标签、软胶按钮、玩具包装元素。
- 动效：挤压回弹、软陶碎屑、轻微转动。
- 成本：高；需要统一三维质感或高质量伪 3D 渲染。

## 6. 已选组合

用户已确认 `L1 柔光收藏馆 + W1 夏日果摊纸雕/折纸`：

- 大厅保持克制中性，突出“这是不同游戏的容器”。
- 合成大西瓜进入后立刻切换为鲜明、独立、具有水果触感的世界。
- 两者不共享色板、控件皮肤或图标，只共享触摸、安全区和状态完整性。
- 游戏封面承担过渡：它在大厅展柜中预告 W1 风格，点击后进入完整 W1 世界。

也可采用反差更强的 `L2 夜航游戏站 + W2 清透果冻实验室`，或更手作的 `L4 减压手帐 + W4 蜡笔果园绘本`。不得直接模仿现有游戏、品牌或特定艺术家的可识别风格。

## 7. 每个视觉单元必须独立冻结的内容

大厅和每个小游戏分别拥有一份主题规范，至少包括：

- 独立主题名称、关键词和禁止方向。
- 独立色板与文字组合。
- 独立字体气质与字号层级。
- 独立圆角、描边、阴影、材质与图标语言。
- 独立按钮、面板、HUD、弹窗和状态设计。
- 独立动效节奏、粒子和音效方向。
- 独立 ImageGen 提示模板、后处理规则和素材台账条目。
- 独立 Bundle 路径、性能降级和销毁验证。

第 6 步只有在大厅方向和合成大西瓜方向各自选定并补全上述规范后才能再次关闭。

## 8. 确认结果

- 大厅方向：`L1 柔光收藏馆`。
- 合成大西瓜方向：`W1 夏日果摊纸雕`，强化纸片分层、折纸折面、纸张压痕和轻量投影。
- 两套正式令牌、控件和素材分别定义在独立规范中，不相互复用。

旧“温暖果园统一视觉”不再是实施依据。后续第 7 步只按大厅 L1 规范生成背景；第 19～24 步只按 W1 纸片折纸规范实现游戏 UI 与素材。

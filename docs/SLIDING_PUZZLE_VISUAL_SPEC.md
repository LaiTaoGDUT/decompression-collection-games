## 1. 主题定位

滑块拼图是一套摆在旧木桌上的复古拼图玩具。玩家应感到方块有重量、边缘有触感、移动有轻微摩擦，但整体仍然清爽、安静、适合长时间单手操作。

关键词：复古木质、纸卡拼图、圆润倒角、温暖桌面、轻机械感、安静满足。

禁止方向：大厅展柜皮肤、猫咪/水果纸雕、2048 霓虹电路、中国象棋书斋木雕、写实旧化脏污、过度复杂的木纹、金属科幻、带版权角色或可识别品牌包装。

## 2. 视觉令牌

| 令牌 | 规划值 | 用途 |
| --- | --- | --- |
| 深胡桃 `#4A2C20` | 主要深色 | 标题、边框、深色文字 |
| 蜂蜜木 `#C9894B` | 主要材质色 | 棋盘外框、强调线 |
| 旧纸 `#F3E2BD` | 内容底色 | 开始页、结果页、按钮面板 |
| 松石绿 `#5B8A78` | 操作强调 | 选中、确认、继续 |
| 砖红 `#A65C45` | 警示/返回 | 取消、返回、错误 |
| 炭墨 `#2D2520` | 正文 | 标题与高对比文本 |
| 暖灰 `#8B7968` | 辅助信息 | 步数、用时、说明 |

颜色使用低到中等饱和度；木纹和纸张纹理只做近距离触感，不允许干扰方块图像辨识。

## 3. 构图与材质

- 背景像温暖木桌或木质玩具盒的内侧，边缘有轻微阴影，中央保持安静。
- 棋盘是页面主视觉，采用厚实圆角木框和浅色内槽；内槽不能使用大厅卡片或 2048 网格。
- 方块采用贴合式网格排布：相邻方块之间只留一条细窄缝隙，缝隙约为单格尺寸的 2%～3%，不能出现卡片式的大块留白；图片贴在 V13 木片皮肤上方，四周只露出极窄底座边缘，方块只做一点点圆角和微小倒角。
- 暂停、参考图、裁剪确认和结算弹窗共用一张 PZ1 弹窗背景图：只包含圆角背景、木质边框和克制的内阴影，不烘焙标题、按钮、图标或动态数据；优先制作成可九宫格缩放的 UI 面板。
- 方块带有细窄的纸卡/木片边缘、轻微内阴影和按压反馈；图片内容保持原始颜色，不能被主题滤镜染成统一色调。
- 空位直接露出棋盘内槽的木质底色，不绘制独立空槽模块，也不放置一块“空白图片方块”；完成状态右下角自然露出内槽。
- 开始页用“玩具说明卡”表达选项，按钮像木质旋钮或压印标签，但动态文字由 Cocos Label 绘制，不把中文烘焙进图片。
- 结果页使用一张完成记录卡，动效集中在棋盘和内槽周围，不做大面积粒子遮挡结果数字。

## 4. 文字与交互

- 标题使用清晰、略带包装标签感的中文无衬线字体；正文保持高可读性，不使用难辨认的手写字体。
- 主要操作文案固定为：“随机一张拼图”“从相册选择”“裁切图片”“开始拼图”“继续上一局的拼图”“重新选择图片/难度”“暂停”“继续”“再来一局”“回大厅”；完成弹窗提供独立的关闭按钮。
- 按钮必须覆盖默认、按下、等待、禁用和失败状态；按下状态使用轻微下沉和阴影变化，不只依赖颜色变化。
- 触摸区域不小于 88×88 设计单位；棋盘手势区与按钮、参考图缩略图不重叠。

## 5. 动效与声音方向

- 进入开始页：木质标题卡轻微落桌，选项卡以短促的纸片回弹出现。
- 方块移动：沿轨道短距离滑入，带非常轻的摩擦/落槽反馈；禁止大幅弹跳导致方块位置难以判断。
- 空位移动：棋盘内槽底色随空位位置自然露出和变化，保持玩家对可移动方向的理解。
- 参考图：缩略图放大为居中纸卡，背景只做低强度暗化，不重置棋盘。
- 完成：最后一块滑入后停顿，木框暖光沿四边扫过，图片轻微呼吸一次，随后展示结果卡。
- 振动：有效落子轻振，完成使用一次中等反馈，暂停/打开参考图不振动；总开关由公共设置控制。
- 音乐和音效必须拥有独立的 PZ1 声音身份：暖木敲击、纸卡摩擦、柔和机械滑轨和短促完成和弦；不使用 T48 电子脉冲、W1 纸片水果音或棋类落子音。

| BGM | 独立可循环器乐，低密度，不抢操作反馈 | `game-sliding-puzzle` |

图片提示词必须明确方形构图、无文字、无水印、可切成网格、中心主体清晰和缩小可读；UI 资源不得生成假中文。音频提示词必须逐条描述触发事件、时长、循环/单次、变体和移动端混音要求。

所有生成或外部制作素材先进入 `计划中`/`待许可确认`，完成来源、许可、后处理、尺寸、压缩、真机和 Bundle 证据后，才能升级为 `可导入` 或 `候选可用`。

## 7. 适配与验收

- 使用 Cocos `Fit Width`，棋盘在矮屏上等比缩小，不通过左右安全区或上下裁切腾空间。
- 标题、暂停、计分和设置避开微信右上角胶囊；布局读取 `Platform.getLayoutInfo()`，不写死单机型坐标。
- Canvas 的 `_cameraComponent` 必须显式绑定有效 UI Camera；Canvas、Camera 和 UI 根节点使用同一 UI Layer。
- 验收至少包含无胶囊 Web、窄屏、高屏、刘海/挖孔设备、不同底部安全区、暗色/亮色系统环境和低档设备降级。
- 视觉验收同时检查：方块图像边界清晰、空位始终可辨、参考图不遮挡返回操作、完成动效不改变模型时序、退出后没有音频/动效残留。

# 服务器本机游戏数据页面

页面提供账号云存档、逐字段最佳进度和逐关星数、成就、同步设备，以及按游戏和设备累加的已上报玩法时长。默认每页 25 个账号，支持账号标识前缀筛选；手动刷新读取数据，没有后台定时轮询。这里的账号是服务端散列标识，不是微信昵称或原始 OpenID。当前时长表是累计值，无法反推出历史每日活跃或每日时长。

## 页面使用

- **数据概览**：查看存档账号、同步设备、累计游玩、最近保存时间，以及最近更新的账号列表和前五名游戏时长。全部时间按北京时间展示。
- **账号存档**：按账号完整标识或十六进制前缀查找，支持大写输入；点击“查看进度”打开侧边详情，复制完整标识后可再次精确查找。
- **账号详情**：在“游戏进度”按游戏名搜索，卡片展示中文指标；有星级的游戏可展开逐关记录。“完整存档字段”保留底层字段用于排查。“成就记录”和“设备与时长”在独立页签展示。
- **游玩统计**：查看全部游戏的累计时长、时长占比、账号数、设备数和最后上报时间，支持按时长或账号数量排序。没有历史每日趋势数据，不展示日活或趋势曲线。

刷新失败时页面保留上一次成功读取的数据并提示失败；恢复 SSH 转发后点击“刷新数据”即可重试。详情内“刷新此账号”仅重读当前账号。查询、翻页、切换详情均为只读操作。

## 安装一次

先按 [OPERATIONS.md](OPERATIONS.md) 发布包含 `viewer/` 的代码包，然后在服务器执行：

```sh
sudo bash /opt/decompression-api/app/install-data-viewer.sh
```

此命令只增加独立查看服务和只读账号。HTTP 固定监听 `127.0.0.1:3100`；不增加 Nginx 域名路径，不开放安全组端口。Linux 用户和 PostgreSQL 角色同名 `decompression-viewer`，通过服务器 Unix socket 的 peer 身份认证，只授予现有三张业务表的 SELECT 权限。服务不读取游戏 API 的 `.env` 或任何 AppSecret，数据库事务另外强制只读。没有 SQL 输入框、修改或删除功能。

## 在电脑浏览器打开

Ubuntu 服务器没有图形桌面。`127.0.0.1` 指向执行浏览器的那台机器，因此需要用已有 SSH 登录方式建立端口转发：

这是[腾讯云官方端口转发文档](https://cloud.tencent.com/document/product/1665/116284)支持的标准 SSH 本地转发方式。该文档也提供 OrcaTerm 桌面客户端的图形配置步骤，并明确目前仅客户端支持端口转发；已有网页终端会话不能直接充当电脑上的本地隧道。

### 使用 OrcaTerm 桌面客户端

1. 在连接管理器添加 SSH 连接：服务器 `139.199.210.76`，端口 `22`，用户名 `ubuntu`，使用已在腾讯云绑定的 SSH 密钥。当前客户端新建连接表单提示登录成功后自动将密钥保存为云端凭据，选择该方式前须确认愿意使用 OrcaTerm 云端托管；私钥内容不要发到聊天或提交到仓库。
2. 首次连接弹出“确认服务器主机密钥”时，通过先前已验证的服务器会话读取 `/etc/ssh/ssh_host_ed25519_key.pub` 的公开指纹，比对客户端显示值后再信任。
3. 点击 OrcaTerm 左侧最上方的四格工具图标，选择“端口转发”→“新建转发”，选择“本地转发”。绑定地址 `127.0.0.1`，本地端口 `3100`；SSH 主机选择刚保存的服务器连接；目标地址 `127.0.0.1`，目标端口 `3100`，备注可填“游戏数据查看”。
4. 保存并启动，确认规则为“运行中”，然后在电脑浏览器打开 `http://127.0.0.1:3100`。使用时保持客户端和转发规则运行；关闭浏览器页面不会停止服务器服务。

本地端口也固定用 `3100`，以匹配查看器的 Host 校验。客户端出现“暂无 SSH 主机”表示还没有可用的连接配置，不能只创建转发规则就直接访问。

如果终端能登录，但启动转发时仍反复要求上传密钥，先在“凭据管理”中新建“密钥托管”，再编辑服务器连接，从密钥下拉框选择该托管凭据并保存。创建凭据时可选本地或云端存储，按自己的保存意愿选择；仅在一次登录窗口里临时上传文件，不一定会形成供转发复用的凭据。

当前这台电脑已配置：连接“游戏服务器 · 数据查看”，转发规则“游戏数据查看”。日常无需新建规则、运行文件或输入终端命令：

1. 打开 OrcaTerm 桌面客户端，点击左侧最上方的四格工具图标，选择“端口转发”；已打开的“端口转发”标签也可直接进入。
2. 找到“游戏数据查看”。右侧显示“启动”时点击它；显示“停止”且圆点为绿色，表示正在运行，无需再点击。
3. 在浏览器打开 `http://127.0.0.1:3100/`。看数据时保持 OrcaTerm 和这条规则运行，可将客户端放到后台。

SSH 终端显示已连接，不代表这条端口转发已启动；不必先打开服务器 Shell。当前没有启用客户端启动时自动启动，退出客户端后重新打开，需要再次启动规则。如果规则显示运行中但页面仍无法读取，可停止再启动一次以重连。

### Mac 双击入口（备用）

本机已有腾讯云绑定的 SSH 私钥时，可双击项目里的 `project-scripts/server/open-data-viewer.command`。它建立本机 `127.0.0.1:3100` 到服务器 `127.0.0.1:3100` 的 SSH 隧道，验证页面健康后打开浏览器；已有健康连接会直接复用。2026-10-27 已验证此备用方式；日常使用按上面的 OrcaTerm 操作即可。

脚本默认使用 `~/Downloads/antcosmos_mac.pem`，也可通过环境变量 `ANTCOSMOS_SSH_KEY` 指定已有私钥路径；私钥需只有本人可读写（600）。脚本使用先前已通过腾讯云会话核验的 Ed25519 主机指纹验证服务器身份，不会关闭主机验证。私钥内容不写入代码或发布包。

```sh
# 建立或复用连接，只输出地址，不打开浏览器
project-scripts/server/open-data-viewer.command --no-open

# 停止本脚本建立的连接
project-scripts/server/open-data-viewer.command --stop
```

此连接独立于 OrcaTerm；关闭 OrcaTerm 不会停止它。电脑重启或网络断开导致隧道退出后，再双击重连。脚本没有安装开机启动任务。与 OrcaTerm 转发共用同一端口时选择其中一种方式：当前已按用户偏好切回 OrcaTerm，备用脚本的独立隧道已停止。

### 使用电脑终端

```sh
ssh -N -T -o ExitOnForwardFailure=yes -o ServerAliveInterval=30 \
  -L 127.0.0.1:3100:127.0.0.1:3100 ubuntu@139.199.210.76
```

这条命令在你自己的 Mac/Windows 电脑终端运行，不是在腾讯云网页终端运行。连接成功后终端保持运行、没有交互命令提示属于正常现象。在电脑浏览器打开 `http://127.0.0.1:3100`。关闭隧道终端或按 Ctrl+C 即停止电脑访问，服务器查看服务继续运行。

首次连接须核对服务器主机指纹；有 SSH 密钥时使用既有 `-i` 配置，有 SSH 密码时在本机终端的隐藏输入提示中输入，不要写在命令或聊天里。仅有腾讯云网页终端的微信扫码登录，不等于已经有电脑 SSH 登录凭据；需要先在腾讯云完成 SSH 密钥绑定或设置登录方式。不要为看页面开放 3100 或 5432 公网端口，也不要把该页面反向代理到公网域名。

## 日常更新与检查

首次安装成功会创建 `/opt/decompression-api/.data-viewer-enabled`。之后普通 `update.sh` 发布成功时会重启查看器，加载新版源码。查看器启动失败会提示 `DATA_VIEWER_WARNING`，游戏接口保持已部署版本；按下面命令排查。首次加入查看器前的旧版本不含 `viewer/`，回退到该版本会停止查看器，游戏 API 正常回退；再部署包含查看器的版本后会恢复。

```sh
sudo systemctl status decompression-data --no-pager
sudo journalctl -u decompression-data -n 50 --no-pager
curl --fail http://127.0.0.1:3100/api/overview
sudo ss -lntp 'sport = :3100'
```

`ss` 的监听地址应为 `127.0.0.1:3100`。查看器占用独立 Node 进程、最多 2 个数据库连接，systemd 内存上限 128MB，查询超时 5 秒。账号量变大后可针对报表增加聚合表，当前不扫描解码全部账号的详细存档。

未来增加新业务数据时，应先增加固定的只读查询和页面展示，再明确授予新表的 SELECT；不要改成通用 SQL 控制台。系统服务模板有改动时重新运行安装命令；普通源码迭代不需要重装。
